CHAPTER 3

評估集合關係：一致性與覆蓋度

Measuring Set Relations: Consistency and Coverage
對應原書第 3 章（中譯本頁 27–44）

補習班門口的紅榜寫著：「本班學生 100% 考上國立大學！」你應該追問兩件事。第一，這個「100%」有多可靠？是 3 個學生全上，還是 200 個學生裡有 170 個上？第二，這條路有多重要？全國考上國立大學的人裡，有多少是從這家補習班來的？前一個問題就是本章的一致性（consistency），後一個就是覆蓋度（coverage）。這兩個指標是之後所有 QCA 分析都會用到的計量基礎。

1. 兩把尺：一致性與覆蓋度 · Two measures

第 1、2 章說過，「某個條件組合是通往結果的其中一條路徑」這種主張，在集合語言裡就是「條件組合 ⊆ 結果」。可是真實資料很少完美，我們需要描述性的數字來回答：證據支持這個集合關係到什麼程度？Ragin 提出兩把尺：

一致性 Consistency

問：共享某個條件組合的案例，在呈現結果這件事上有多一致？也就是資料離「完美子集合」有多近。

類比：相關分析的顯著性——這個關係值不值得認真看待？一致性不夠，理論就沒有得到支持。

覆蓋度 Coverage

問：這個條件組合「解釋」了多少結果的實例？當通往結果有很多條路時，某一條路的覆蓋度可能很小。

類比：相關分析的強度——它衡量經驗上的切題性（empirical relevance）或重要性。

同樣兩把尺也能用在必要條件上（結果 ⊆ 條件）：這時一致性衡量「有結果的案例是否都具備該條件」，覆蓋度則衡量這個必要條件是否切題，也就是條件與結果的實例「配對」得多緊密（本章這部分延續 Goertz 等人關於必要條件的研究）。

🔑 一句話記住

就像統計上可以「非常顯著但相關很弱」，集合分析也可以「一致性很高、覆蓋度很低」。兩者回答不同的問題，缺一不可。

2. 清晰集的一致性：「接近也算數」 · Crisp-set consistency

完美的集合關係在社會科學很少見，通常只出現在小樣本或總體層次的資料中。例外幾乎總是存在——「民主國家彼此不開戰」也有爭議案例。所以我們需要一個數字來表示「有多接近」。

清晰集的一致性非常簡單：具有該條件（組合）的案例中，呈現結果的比例。回到第 1 章的第三波民主化：

  • 3 個議會制國家，3 個民主化失敗 → 一致性 3/3 = 1.0；
  • 20 個議會制國家，17 個民主化失敗 → 一致性 17/20 = 0.85。

直覺上，多數研究者會更相信第二種情況——雖然不是 100%，但 20 個裡有 17 個，至少顯示有值得追究的整體關係。3 個全中則可能只是巧合。Ragin 稱這種精神為「接近也算數（close counts）」。

ℹ️ 把案例數考慮進來：機率檢定

Ragin（2000）建議可以設定一個基準值（例如 0.65 或 0.75），用精確的二項檢定問「觀察到的一致性是否顯著高於基準？」。以 α = 0.05、基準 0.65 為例：3/3 的單尾 p 值為 0.65³ ≈ 0.275，不顯著；17/20 的 p 值約 0.044，顯著。一般原則是一致性越接近 1.0 越好；低於 0.75 時，要主張集合關係存在就相當困難了。

3. 模糊集的一致性（充分性） · Fuzzy-set consistency

模糊集讓隸屬度可以落在 0 到 1 之間（例如某國「部分屬於」民主國家）。第 2 章說過，模糊子集合關係的定義是：每個案例在 X 的隸屬度都 ≤ 它在 Y 的隸屬度（Xi ≤ Yi）。

哪些案例「不算」反例？

延續議會制的例子。某國在「民主化失敗」的隸屬度 0.90、在「議會制」只有 0.20——這不違反「議會制 ⊆ 失敗」，因為失敗還有很多別的路（這就是清晰集中「總統制但也失敗」的模糊版本）。相反地，若某國「議會制」0.80、「失敗」只有 0.30，那就是明確的反例。

畫成 XY 圖時，模糊子集關係呈三角形：所有點都在主對角線上或其上方。

  • 左上三角的案例（X 低、Y 高）並不違反「X 是充分但不必要」的主張——它們透過別的路徑得到結果。所以 X 低的時候，Y 可以在很寬的範圍內。
  • X 越高，Y 能落的範圍就越窄（必須 ≥ X），違反子集關係的機會也越多。
  • 但在傳統相關分析裡，左上三角的點會被當成「離群值」，因為它們拉低了 X 與 Y 的相關。

舊方法的問題：每個案例一票

Ragin 在《模糊集社會科學》（2000）裡把一致性定義為：XY 圖中落在對角線上或上方的案例比例。若 80% 以上的案例在對角線上方，就說 X「幾乎總是」充分。這其實就是把清晰集的模板直接搬過來，問題是它忽略了隸屬度的強弱：

不一致的案例，被一視同仁

  • 案例甲：X = 0.25、Y = 0（X 本來就偏「不屬於」）
  • 案例乙：X = 1.0、Y = 0.75（X 是完全隸屬的典型案例）

兩者 X 都超過 Y 0.25，舊方法各算「一個不一致」。但乙是這個條件組合更好的代表，它的不一致對理論更有殺傷力。

一致的案例，也被一視同仁

  • X = 0.9、Y = 1.0（兩者都高）
  • X = 0.1、Y = 0.2（兩者都低）
  • X = 0.15、Y = 0.8（X 低、Y 高）

第一個顯然最能支持論點。想像你拿一個在相關集合裡隸屬度很低的案例去說服同事——白費時間。X 隸屬度高的案例，提供最切題的一致案例，也提供最切題的不一致案例。

Ragin 的推導分三步（數字都已用程式重算核對）：

第一步：一致案例的 X 總和 ÷ 全部 X 總和

表 3-1 全部一致 → 4.7 / 4.7 = 1.0。現在把案例 1 的 X 從 0.7 改成 1.0（Y 仍是 0.9），它變成不一致。分母變 5.0，分子只剩其他 11 個一致案例的 4.0 → 4.0 / 5.0 = 0.80。只因一個「差一點點」的案例，就從 1.0 掉到 0.80，跌幅太大了。

第二步：把不一致案例中「仍然一致的部分」加回分子

案例 1 的 X = 1.0，其中「到 Y = 0.9 為止」的 0.9 其實是和結果一致的。把 0.9 加回分子：4.9 / 5.0 = 0.98。這才合理——只有一個案例不一致，而且非常接近一致。

第三步：大不一致會被重罰

若案例 1 是 X = 1.0、Y = 只有 0.3，分子只能加回 0.3：4.3 / 5.0 = 0.86。同樣是「一個不一致案例」，超出得越多，扣得越多。

把第二、三步寫成公式，就是今天 fsQCA 與 R 都在用的充分性一致性（「模糊包含」的計算方式）：

充分性一致性（X ⊆ Y） Consistency(Xi ≤ Yi) = Σ min(Xi, Yi)Σ Xi

每個案例對分子貢獻 min(X, Y)：一致的案例（X ≤ Y）貢獻整個 X；不一致的案例只貢獻到 Y 為止。所以：全部 X ≤ Y 時等於 1.0；少數案例略為超出時接近 1.0；很多案例大幅超出時，可能掉到 0.5 以下。這個公式套在 0/1 的清晰集資料上，就會還原成「一致案例的簡單比例」，所以清晰集與模糊集通用；第 2 節的機率檢定也可以照用。

4. 必要條件的一致性 · Consistency of necessity

同一套想法可以用來評估必要條件。當結果的實例構成條件實例的子集合（Y ⊆ X）時，必要性得到支持。在模糊集裡，就是看結果的隸屬度是否一致地 ≤ 條件的隸屬度：Yi ≤ Xi。

  • 這時所有點都落在對角線上或下方。
  • 右下角的案例（X 高、Y 低）不違反必要性：它們有必要條件，但缺了其他某些條件，所以沒有結果——畢竟必要不等於充分。（相關分析又會把它們當離群值。）
  • 反過來，X 低的時候 Y 也必須低；在 X 的低端，Y 能落的範圍很窄，違反的機會最多。

因為必要性的不等式（Y ≤ X）剛好和充分性（X ≤ Y）相反，公式只要把分母換成 ΣY：

必要性一致性（Y ⊆ X） Consistency(Yi ≤ Xi) = Σ min(Xi, Yi)Σ Yi

所有 Y ≤ X 時等於 1.0；很多 Y 大幅超過 X 時會低於 0.5。

⚠️ 因果關係不在資料裡

無論是必要性或充分性，詮釋都必須建立在理論與實質知識上。集合論的一致性只是研究者主張充分性、必要性或其他因果／構成關係時，提供的其中一項支持證據。

5. 覆蓋度：這條路有多重要？ · Coverage of sufficient conditions

考慮到等效性（equifinality）與因果複雜性，同一個結果常常可由好幾種條件組合產生，我們把它們看成通往結果的不同「配方」。在清晰集分析中，自然會問：經由某條路徑得到結果的案例，占全部結果案例的多少？這個比例就是覆蓋度——某條路徑經驗重要性的直接指標。

📌 一致性與覆蓋度常常互相拉扯

條件組合越複雜（交集越多集合），越容易一致，但覆蓋的人越少。例如：在校成績優異 × 考試高分 × 父母受大學教育 × 父母高收入 × 常春藤畢業的美國成年人，幾乎 100% 不會貧窮——但在所有不貧窮的人裡，這種人少得可憐。這樣的「完美一致」實務上並不令人信服，因為覆蓋度微不足道。

原書註：覆蓋度只衡量經驗重要性，不是理論重要性。一條罕見（低覆蓋）的路徑，可能證明了理論上被認為不可能的路其實可行，因而在理論上很關鍵。

🔑 鐵律：先一致性，後覆蓋度

只有在確認集合關係一致之後，計算覆蓋度才有意義。去算一個「不是結果一致子集合」的條件的覆蓋度，是沒有意義的。而且下面會看到，同一個算式在不同情境下意義不同——遵守這個順序，才不會搞混。

從清晰集到模糊集：重疊 ÷ 結果大小

把覆蓋度想成維恩圖：子集合（高教育）在物理上「蓋住」目標集合（不貧窮）多大一塊。兩個模糊集的重疊大小就是它們交集的總和，也就是一致性公式的分子：

重疊（overlap） Overlap = Σ min(Xi, Yi)

結果集合的「大小」就是它的隸屬度總和 ΣY（對應清晰集的人數）。所以：

充分性覆蓋度（X ⊆ Y） Coverage(Xi ≤ Yi) = Σ min(Xi, Yi)Σ Yi

也就是把一致性公式的分母 ΣX 換成 ΣY。以表 3-1 為例：Σmin = 4.7、ΣY = 7.2 → 覆蓋度 = 4.7 / 7.2 ≈ 0.653。

⚠️ 同一個算式，兩種意義

Σmin(X,Y)/ΣY 也正是第 4 節「必要性一致性」的公式！差別在情境：

  • 充分性情境：已經確認大部分 X ≤ Y，現在要問 X 相對於 Y 有多大 → 讀作「覆蓋度」。
  • 必要性情境：期待大部分 Y ≤ X，要檢查 Y 是不是 X 的一致子集合 → 讀作「一致性」；若遠低於 1.0，表示 Y 不是 X 的一致子集合。

怎麼讀這張圖：每個點左邊的綠色虛線長度是該案例被算為「一致」的部分 min(X,Y)，會加進覆蓋度的分子；虛線端點到對角線之間的粉紅線段，是 Y 沒有被 X 蓋住的部分。

  • 只有兩個點在對角線下方（違反一致性），子集合關係大致成立。
  • 離 Y 軸近、離對角線遠的點（X 遠小於 Y），雖然符合 X ≤ Y，對覆蓋度貢獻很少——特別是當 Y 大於 0.5 時。
  • 只有當 X 大致等於 Y（點貼著對角線）時，覆蓋度才會很高。
想一想：覆蓋度 = 1.0 是不是代表 X 和 Y「完全相關」？

不是。原書註腳特別區分集合重合（set coincidence）與相關：在模糊集 XY 圖上，任何非水平、非垂直的直線都代表完全相關；但只有當所有點都精確落在主對角線上時，才是完全的集合重合。集合重合是相關的一個特例。衡量兩個集合重合程度的簡單指標是 Σmin(X,Y) / Σmax(X,Y)。表 3-1 的重合度 = 4.7 / 7.2 ≈ 0.653（因為每列都 X ≤ Y，max 就是 Y）。

6. 必要條件的切題性與評估準則（表 3-4） · Relevance of necessary conditions

覆蓋度也能用在必要條件上。Goertz（2003, 2006）的重點是區分重要的和微不足道（trivial）的必要條件：

  • 微不足道：在大多數案例中都強烈存在，不管有沒有結果。例如「不滿」可能是社會運動的必要條件，但不滿幾乎無所不在，很少因為「缺乏不滿」而擋下社會運動。
  • 重要：例如「開放、寬容的政治環境（沒有政府壓制）」，因為社會運動常常遭到壓制，這個條件真的會發揮限制作用。

Ragin 的具體公式和 Goertz 不同，但目標相似：用 Y 對 X 的覆蓋度衡量 X 作為必要條件的切題性。

必要性覆蓋度／切題性（Y ⊆ X） Coverage(Yi ≤ Xi) = Σ min(Xi, Yi)Σ Xi

覆蓋度很小，代表 X 對 Y 的限制效果可以忽略。經典例子：美國幾乎所有海洛因成癮者以前都喝過牛奶，但「喝過牛奶」不是有意義的必要條件——成癮者這個集合，和「喝過牛奶的人」相比實在太小了。反之，若「曾和成癮者往來」的人中有相當比例後來成癮，而且幾乎沒有成癮者事先沒和成癮者往來，那麼覆蓋度很高，「和成癮者往來」就是切題的必要條件。

7. 分隔覆蓋度：原始、唯一與解的覆蓋度 · Partitioning coverage

當有不只一條路徑對結果充分（等效性）時，各路徑的覆蓋度直接告訴我們它們的相對經驗重要性。更進一步，可以仿照多元迴歸「分割解釋變異」的做法，把覆蓋度切成：

  • 原始覆蓋度（raw coverage）：某條路徑單獨計算的覆蓋度（含與其他路徑重疊的部分）。
  • 唯一覆蓋度（unique coverage）：只有這條路徑解釋、其他路徑都沒解釋到的部分。
  • 解的覆蓋度（solution coverage）：所有路徑以邏輯「或」聯集後的覆蓋度（原書稱為「總覆蓋度」或「雙路徑模型的覆蓋度」）。

前提：已經證明每條路徑都是結果的一致子集合。

清晰集的直覺：Y = A·B + C·D

研究者找到兩條路徑：A·B 覆蓋結果的 25%，C·D 覆蓋 30%。但兩者聯集只覆蓋 35%，遠小於 25% + 30% = 55%。為什麼？因為兩條路部分重疊：有些案例四個條件全有（A·B·C·D），分別計算原始覆蓋度時被算了兩次。用減法就能拆開：

  • A·B 的唯一覆蓋度 = 0.35 − 0.30（C·D 的覆蓋度）= 0.05
  • C·D 的唯一覆蓋度 = 0.35 − 0.25（A·B 的覆蓋度）= 0.10
  • 重疊（A·B·C·D）= 0.35 − 0.05 − 0.10 = 0.20
唯一覆蓋度（以兩條路徑為例） Unique(P1) = Coverage(P1 + P2) − Coverage(P2)

多條路徑時，一般化為：解的覆蓋度 − 拿掉這條路徑後其餘路徑聯集的覆蓋度。這和迴歸裡「把 X1 從完整模型拿掉，看 R² 減少多少」是同樣的邏輯。不過目的不同：迴歸在處理相關的自變數；集合分析裡條件本來就不是彼此孤立的，要分隔是因為有些案例同時符合好幾條路徑。

模糊集的實例：避免貧窮（表 3-5、3-6）

資料來自美國全國青年縱貫調查（NLSY，即《鐘形曲線》資料），樣本為白人男性。結果是「不貧窮」（~P），三個條件是：高測驗分數（T）、高收入父母（I）、受大學教育（C）（校準方式見第 11 章）。fsQCA 得到兩條避免貧窮的路徑：T·I 與 C。

8. 實作：在 fsQCA 與 R 計算一致性與覆蓋度 · Practical appendix

原書本章沒有獨立的操作附錄，以下是補充的實作說明：如何用軟體算出本章的各項指標，並做必要條件分析。

準備資料

每一欄是一個已校準的集合（0–1），每一列是一個案例。第一列為變數名稱（不可有空格或標點）。可以從 CSV 匯入。

先畫 XY 圖

Graphs → XY Plot（各版本選單位置略有不同）：X 軸放條件、Y 軸放結果。圖上會同時顯示一致性與覆蓋度，請先看點的分布是三角形（充分）還是倒三角形（必要）。

必要條件分析

Analyze → Necessary Conditions：選擇結果，逐一加入條件（可加 ~ 取否定）。報表給出 Consistency（= Σmin/ΣY）與 Coverage（= Σmin/ΣX）。一般以一致性 ≥ 0.9 作為必要條件的門檻，再看覆蓋度判斷是否微不足道。

組合變數的一致性

想檢查某個條件組合，可用 Variables → Compute 以 fuzzyand(T, I)、fuzzyor(…)、fuzzynot(…) 建立新變數，再放進 XY 圖或必要條件分析。

讀解的報表

執行 Analyze → Truth Table Algorithm 並最小化之後，每一條路徑都會列出 raw coverage、unique coverage 與 consistency，最後是 solution coverage 與 solution consistency。記得先看 consistency 再看 coverage。

R 的 QCA 套件（Duşa）中，pof() 計算一致性（inclS / inclN）與覆蓋度（covS / covN），superSubset() 搜尋必要條件，XYplot() 畫 XY 圖。

library(QCA)

# 原書表 3-1：強勢左派 (LEFT) 與高福利國家 (WELF)
d31 <- data.frame(
  LEFT = c(.7,.1,.1,.3,.9,.7,.3,.3,.3,.1,0,.9),
  WELF = c(.9,.9,.1,.3,.9,.7,.9,.7,.7,.1,0,1)
)

# 充分性：inclS = Σmin/ΣX = 1.000；covS = Σmin/ΣY ≈ 0.653
pof("LEFT", outcome = "WELF", data = d31, relation = "sufficiency")

# 必要性：inclN = Σmin/ΣY ≈ 0.653（不夠一致，不必再看 covN）
pof("LEFT", outcome = "WELF", data = d31, relation = "necessity")

# 手算對照
with(d31, sum(pmin(LEFT, WELF)) / sum(LEFT))   # 1.000

# 把案例 1 改成 1.0：一致性降為 0.98
d31$LEFT[1] <- 1
pof("LEFT", outcome = "WELF", data = d31, relation = "sufficiency")

# XY 圖（充分性：點應在對角線上方）
XYplot("LEFT", "WELF", data = d31, relation = "sufficiency")

分隔覆蓋度：建一份符合「A·B 覆蓋 25%、C·D 覆蓋 30%、聯集 35%」的清晰集資料（20 個結果案例 + 10 個非結果案例），用 pof() 一次取得原始（covS）與唯一（covU）覆蓋度：

rows <- rbind(
  matrix(c(1,1,0,0,1), 1,  5, byrow = TRUE),  # 只有 A·B
  matrix(c(1,1,1,1,1), 4,  5, byrow = TRUE),  # A·B·C·D（重疊）
  matrix(c(0,0,1,1,1), 2,  5, byrow = TRUE),  # 只有 C·D
  matrix(c(0,0,0,0,1), 13, 5, byrow = TRUE),  # 經由其他路徑
  matrix(c(0,0,0,0,0), 10, 5, byrow = TRUE))  # 沒有結果
dd <- setNames(as.data.frame(rows), c("A","B","C","D","Y"))

pof("A*B + C*D", outcome = "Y", data = dd, relation = "sufficiency")
# A*B：covS 0.25、covU 0.05；C*D：covS 0.30、covU 0.10；expression：covS 0.35

# 必要條件搜尋：一致性 ≥ 0.9 且覆蓋度 ≥ 0.5 的條件（或其聯集）
superSubset(dd, outcome = "Y", conditions = c("A","B","C","D"),
            relation = "necessity", incl.cut = 0.9, cov.cut = 0.5)

報表欄位對照：inclS = 充分性一致性、covS = 原始覆蓋度、covU = 唯一覆蓋度；必要性則看 inclN、covN（套件另提供 RoN，是另一種判斷必要條件是否微不足道的指標）。報表中的 PRI 會在後面章節介紹。完整操作見本站主教材〈Ch.4 模糊集 fsQCA〉。

9. 本章重點、名詞與自我測驗 · Review

  1. 一致性衡量資料離完美子集合關係有多近（類似顯著性）；覆蓋度衡量該條件解釋了多少結果實例（類似強度、經驗切題性）。
  2. 清晰集一致性 = 具有條件的案例中呈現結果的比例；要考慮案例數（3/3 不如 17/20 可信），低於 0.75 就很難主張集合關係。
  3. 模糊集充分性一致性 = Σmin(X,Y)/ΣX：用隸屬分數加權，小不一致小扣、大不一致重扣，比「對角線上方案例比例」合理。
  4. 必要性一致性 = Σmin(X,Y)/ΣY；必要性覆蓋度（切題性）= Σmin(X,Y)/ΣX，用來分辨重要與微不足道的必要條件。
  5. 充分性覆蓋度 = Σmin(X,Y)/ΣY。同一算式在充分與必要情境意義不同，所以必須先確認一致性，才計算覆蓋度（表 3-4）。
  6. 多條路徑時要分隔覆蓋度：原始覆蓋度含重疊；唯一覆蓋度 = 解的覆蓋度 − 拿掉該路徑後的覆蓋度；兩者之差反映路徑間的重疊。

自我測驗

在 Ragin 的類比中，一致性與覆蓋度分別對應相關分析的什麼？

一致性問「這個關係值不值得認真看待」（類似顯著性）；覆蓋度問「它在經驗上有多重要」（類似強度）。所以也會有「一致性高、覆蓋度低」的情況。

表 3-1 中，若案例 1 改為 X = 1.0、Y = 0.9，用 Σmin(X,Y)/ΣX 計算的一致性是多少？

ΣX 變成 5.0；不一致案例仍貢獻 min(1.0, 0.9) = 0.9，分子 4.0 + 0.9 = 4.9。0.80 是只算一致案例的舊算法，0.917 是對角線上方案例比例，0.86 是 Y = 0.3 時的結果。

下列哪一個公式是「必要性一致性」？

必要性是 Y ⊆ X，要看 Y 有多少落在 X 裡，所以分母是 ΣY。它和充分性覆蓋度的算式相同，但情境與意義不同。

表 3-3 中，高教育者的一致性是 0.967，覆蓋度只有 0.0325。最恰當的解讀是？

一致性高 → 子集合關係成立；覆蓋度低 → 不貧窮的人絕大多數不是經由這條路。兩者並不矛盾，正好說明為什麼兩把尺缺一不可。

「幾乎所有海洛因成癮者以前都喝過牛奶」，但喝牛奶不是有意義的必要條件。用本章的指標說，原因是？

一致性其實很高（成癮者幾乎都喝過牛奶），但「喝過牛奶的人」這個集合太大，成癮者只占其中極小部分，所以覆蓋度極低，是微不足道的必要條件。

兩條路徑的原始覆蓋度分別為 0.25 與 0.30，解的覆蓋度為 0.35。第一條路徑的唯一覆蓋度是？

唯一覆蓋度 = 解的覆蓋度 − 拿掉該路徑後的覆蓋度 = 0.35 − 0.30 = 0.05。0.10 是第二條路徑的唯一覆蓋度，0.20 是重疊部分。

在模糊集中，計算兩條路徑 T·I 與 C「聯集」的隸屬度時，每個案例取什麼值？

邏輯「或」（+）在模糊集中取最大值：max(T·I, C)。接著用同樣的 Σmin(X,Y)/ΣY 計算解的覆蓋度。

某研究者對一個充分性一致性只有 0.55 的條件，報告它的覆蓋度高達 0.80，並宣稱它是重要路徑。問題在哪？

本章的鐵律：先一致性，後覆蓋度。X 不是 Y 的一致子集合時，「X 蓋住 Y 多少」這個問題根本不成立。
