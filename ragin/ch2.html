1. 為什麼需要模糊集 · Why fuzzy sets?

第 1 章說服我們：社會科學的理論多半是集合陳述，應該用集合關係來檢驗。但馬上會有人反駁——

常見的質疑

  • 很多國家介於「民主」與「不民主」之間，硬分成 0／1 太粗糙。
  • 名義尺度（nominal scale）被認為是「原始」的測量。
  • 把定距（interval）、定比（ratio）變數切成二分類，等於把資訊「降級」，而且切點選在哪裡？研究者會不會挑一個對自己有利的切點？

模糊集的回應

  • 用 0 到 1 之間的分數表示部分隸屬，保留程度差異。
  • 同時保留子集合、交集、聯集等集合論的核心運算。
  • 數學基礎是 Zadeh（1965）提出的模糊集合理論，是一套成熟的數學體系。

換句話說，模糊集讓我們可以問「已開發國家是不是民主國家的子集合？」——即使開發程度與民主程度都是用細緻的連續尺度衡量，也不必退回清晰集。

2. 模糊集的本質：隸屬分數與定性錨點 · The nature of fuzzy sets

模糊集同時是質性的也是量化的：它像連續變數一樣能表達程度，但每個分數都有「在集合裡有多深」的質性意義。Ragin 舉的例子是：美國在「已開發國家」集合的隸屬分數可以是 1.0（完全隸屬），但在「民主國家」集合可能只有 0.9（很接近、但不完全隸屬）——尤其考量到 2000 年總統大選的爭議。

🔑 三個定性錨點（qualitative breakpoints）

1.0 ＝ 完全隸屬（full membership）：毫無爭議地屬於這個集合。
0.5 ＝ 交叉點（crossover point）：最模糊的點——說它「偏在裡面」或「偏在外面」都一樣有道理。
0.0 ＝ 完全不隸屬（full non-membership）：毫無爭議地不屬於這個集合。

其他分數都相對於這三個錨點來解讀：0.8、0.9 是「強隸屬但不完全」；0.2、0.3 是「偏向不隸屬，但仍是很弱的成員」。大於 0.5 = 偏在集合內；小於 0.5 = 偏在集合外。

所以，模糊集可以看成一種經過有目的的校準（calibrated）的連續變數：它被刻意調整成「表示案例在某個定義清楚的集合裡的隸屬程度」。決定三個錨點必須靠理論知識與實質知識（第 4、5 章會詳述）。例如，某個連續變數低端的案例可能全部「完全不隸屬」（分數一律截為 0），高端的案例則全部「完全隸屬」（一律截為 1）。

3. 模糊集不是一般變數：校準要有目的 · Calibration, not mere measurement

四值、六值模糊集 ≠ 定序量表

乍看之下，0／0.2／0.4／0.6／0.8／1 很像一個六級的定序量表（ordinal scale）。但兩者根本不同：

  • 定序量表只是把類別相對排序（第 1 名、第 2 名……），每個類別與「是否屬於某集合」沒有關係。
  • 模糊集分數則每個值都對照外部標準：0 就是「完全不屬於」，1 就是「完全屬於」。
📌 Ragin 的例子：六級國家財富量表 → 「富裕國家」模糊集

假設你有一個從「極貧」到「超級富有」的六級財富定序量表。把它機械地換成 0、0.2、0.4、0.6、0.8、1 是錯的。比較合理的轉換可能是：

定序等級1（最窮）23456（最富）
機械換算 ✘00.20.40.60.81
有目的的校準 ✔000.3依實質知識判斷11

最低兩級都「完全不富裕」，最高兩級都「完全富裕」，第三級可能只值 0.3（而不是 0.2）。關鍵是：定序類別的實質內容，與研究者如何定義、命名這個集合是否吻合。校準應該深思熟慮，而不是機械操作。（第 4 級的分數原書未給，這裡留白以示需要判斷。）

連續模糊集：兩個嚴重錯誤

以「人均國民生產毛額（GNP per capita）」建構「富裕國家」連續模糊集為例，Ragin 點名兩種嚴重錯誤：

  1. 把最窮的國家設為 0、最富的設為 1，其他國家依數值等比例放在中間。
  2. 依國家的排名來分配隸屬分數。

正確做法是先找出三個定性錨點：毫無爭議的富裕國家從哪裡開始（完全隸屬）、毫無爭議的不富裕國家到哪裡為止（完全不隸屬）、以及最難判斷的交叉點（0.5），而且每個錨點都要能說出理由。

從「富裕國家」這個集合來看，兩個非常富有的國家之間的 GNP 差距是無關的變異（irrelevant variation）：它們都是 1。同理，兩個非常貧窮國家的差距也與「富裕」無關，它們都是 0。只開發一個能排出相對位置的指標（如人均 GNP）是不夠的，還必須用知識把指標分數連結到集合隸屬。

想一想：同一個人均 GNP，為什麼可能得出完全不同的隸屬分數？

因為隸屬分數是相對於「集合的定義」而來的。如果研究焦點從「富裕國家」改成「中等收入國家」，最富有的國家在新集合中反而會是 0（它們不是「中等」），中段國家才會接近 1。指標沒變，概念與標籤變了，分數就跟著變——這正是模糊集與「一般變數」最大的不同。

4. 模糊集的三種基本運算 · Negation, logical and, logical or

使用模糊集評估集合關係時，結果與前因條件都可以用模糊隸屬分數表示（清晰集條件與模糊集條件也可以混用）。Ragin 用一個先進工業民主國家的階級投票（class voting）例子示範：結果是「弱階級投票國家」集合（W），以 Nieuwbeerta（1995）彙整的二戰後調查資料為基礎。四個前因條件是：

  • A：高度富裕國家　I：所得不平等國家（理論上兩者削弱階級投票）
  • M：製造業就業率高的國家　U：工會強大的國家（理論上兩者強化階級投票）

全部都是六值模糊集，反映各國二戰後的一般特徵。Ragin 也強調：這裡的重點是示範操作程序，不是校準方式或最佳的解釋模型。

① 否定（negation，「非」）

否定~X = 1 − X

清晰集的否定是把 1 變 0、0 變 1；模糊集的否定是同一個原理推廣到 0 與 1 之間。例：美國在「高製造業就業」集合的分數是 0.4，所以在「非高製造業就業」集合（~M）中是 1 − 0.4 = 0.6。表 2-2 的 ~M 欄就是 12 國的否定分數。

② 交集（intersection，邏輯「且」）

交集A·B = min(A, B)

假設研究者想列出「製造業不發達、但非常富裕」的國家。傳統做法是把兩個變數各自二分，做成 2×2 表，挑出「非高製造業 × 高度富裕」那一格——那一格其實就是兩個清晰集的交集。在模糊集中，案例在組合集合的分數取各組成集合分數的最小值。例：美國 ~M = 0.6、A = 1.0，所以 A·~M = min(1.0, 0.6) = 0.6（偏隸屬）。

ℹ️ 為什麼是取最小值？

直覺：一條鏈子的強度取決於最弱的那一環。要同時具備「富裕」與「非製造業」兩個特徵，你在組合中的隸屬程度不可能高於你在其中較弱那一項的程度。這也和清晰集一致：只要有一個是 0，交集就是 0。

③ 聯集（union，邏輯「或」）

聯集A + B = max(A, B)

如果研究者猜想「非高製造業」或「高度富裕」可能是通往弱階級投票的可互相替代的基礎，就會對兩者的聯集感興趣。模糊聯集取各組成集合分數的最大值。例：某國 A = 0.2、~M = 0.8，則 A + ~M = max(0.2, 0.8) = 0.8。

⚠️ 初學者常見誤解

符號「·」和「+」不是乘法和加法！A·~M 不是 0.6 × 1.0，A + ~M 也不是 0.2 + 0.8 = 1.0（那個 1.0 碰巧對，換個例子就錯了：0.6 + 0.8 = 1.4 已經超出 0–1）。在本書中，「·」= 取最小值，「+」= 取最大值，「~」= 用 1 去減。

5. 模糊子集關係與 XY 圖 · Fuzzy subset relations

模糊集的最大優點，是它既保留細緻的實證等級（empirical gradations），又能做集合論分析。我們可以直接問「已開發國家是否為民主國家的子集合？」而不用退回名義尺度。

先回顧清晰集怎麼做（原書表 2-3）

用清晰集檢驗「某條件組合 ⊆ 結果」很簡單：把具備該條件組合的案例挑出來，看它們的結果是否一致。

條件組合缺席條件組合存在
結果存在格 1：與評估無直接關係格 2：支持「條件組合 ⊆ 結果」
結果缺席格 3：與評估無直接關係格 4：應該是空的（或幾乎空的），這裡的案例削弱論點

格 4 空著、格 2 有案例，子集合關係就成立。（當然格 4 不一定完全是空的，但在案例導向研究中，研究者應該能解釋落入格 4 的少數案例。）

模糊集版本：逐案比較分數

模糊集不能直接這樣做：每個案例的分數幾乎各不相同，沒辦法簡單「挑出具備條件的案例」。但模糊代數提供了直接的判準：

🔑 模糊子集關係的定義

如果每一個案例在集合 X 的分數都小於或等於它在集合 Y 的分數（Xi ≤ Yi），則 X 是 Y 的模糊子集合：X ⊆ Y。

當 X 是條件（或條件組合）、Y 是結果時，這就是充分性的型態：條件分數高，結果分數也必須高；但反過來不必成立。

📌 回到第 1 章的三個要點

考慮這句話：「在先進工業民主國家中，缺乏強大工會的國家，階級投票就弱。」

① 它主張了一個明確連結：非強大工會 ⊆ 弱階級投票。
② 它是非對稱的：並沒有說工會強大的國家就不會弱階級投票，所以愛爾蘭、比利時並不構成反證。
③ 集合關係可以很強，即使相關不完美：圖 2-1 中所有案例都在左上三角形，集合關係完美成立；但 Pearson r 只有 0.766（我們重算結果亦為 0.766）。

想一想：為什麼左上方的點會拉低相關係數，卻不影響子集關係？

相關係數衡量的是「點離一條最適直線有多遠」，愛爾蘭（0.2, 0.8）離任何直線都很遠，所以會拉低 r。但子集關係只問一件事：「有沒有點跑到對角線下方？」愛爾蘭在對角線上方，完全合法。這就是第 1 章「格 1 削弱相關、但不削弱充分性」在模糊集中的翻版。

展望

現實資料很少像圖 2-1 這麼完美。第 3 章會介紹兩個描述性指標：一致性（consistency）——資料與集合關係陳述吻合到什麼程度；以及覆蓋度（coverage）——這個關係在實證上有多重要。

6. 實作：畫出模糊集合關係 · Practical appendix

用簡單的 XY 圖就能找出模糊集合關係：在這種三角形圖中，點一致地落在對角線上方（或一致地落在下方），就表示存在某種模糊子集關係。

建立模糊集資料

隸屬分數可以直接賦值，也可以依第 4、5 章的校準程序計算。可在 fsQCA 中直接輸入，或匯入 CSV（Excel）、Tab 分隔檔（SPSS）。第一列是簡單的變數名稱（見第 1 章附錄）。

開啟 XY 圖

資料顯示在試算表視窗後，點選 Graphs → XY Plot（舊版還要先點 Fuzzy，新版已省略）。用下拉箭頭指定 X 軸與 Y 軸的變數。

（可選）否定與案例標籤

畫圖前可勾選變數名稱旁的「Negate」框來使用否定集（例如把 U 變成 ~U）；也可指定「case Id」變數，方便辨認圖上的點是哪個案例。

繪圖並檢查型態

按 Plot，看點是落在對角線上方還是下方。點擊任一點，其資訊會顯示在圖的下方。

角落的兩個數字

圖左上角與右下角方框中的數字是一致性與覆蓋度，第 3 章會解釋。

補充（非原書附錄）：計算交集、聯集、否定

若要新增 A·~M 之類的欄位，可用 Variables → Compute，在運算式中使用 fsQCA 提供的模糊函數，例如 fuzzyand(A, fuzzynot(M))、fuzzyor(A, fuzzynot(M))。函數名稱請以你所用版本的 Compute 對話框列出者為準。

以下用 R 的 QCA 套件重現表 2-2、表 2-4 與圖 2-1：

library(QCA)

# 原書表 2-2：先進工業國家階級投票（六值模糊集）
cv <- data.frame(
  W = c(.6,.6,.2,.8,.6,.8,.6,.8,.2,0,.4,1),   # 弱階級投票
  A = c(.8,.6,.6,.6,.6,.2,.4,.6,.6,.8,.6,1),   # 高度富裕
  I = c(.6,.2,.4,.8,.8,.6,.8,.4,.4,.4,.6,.8),  # 所得不平等
  M = c(.4,.2,.2,.2,.4,.8,.2,.2,.6,.8,.8,.4),  # 高製造業就業
  U = c(.6,.8,.8,.2,.4,.8,.6,.4,.8,1,.6,.2),   # 強大工會
  row.names = c("AUS","BEL","DNK","FRA","DEU","IRL",
                "ITA","NLD","NOR","SWE","GBR","USA")
)

# 三種運算：否定 = 1 - x；交集 = fuzzyand()（即 pmin）；聯集 = fuzzyor()（即 pmax）
cv$notM      <- 1 - cv$M
cv$A_notM    <- fuzzyand(cv$A, 1 - cv$M)   # 原書表 2-2 第 8 欄 A·~M
cv$A_or_notM <- fuzzyor(cv$A, 1 - cv$M)    # 原書表 2-2 第 9 欄 A + ~M
cv

# 表 2-4：~U 是否為 W 的模糊子集合？
notU <- 1 - cv$U
all(notU <= cv$W)        # TRUE：每個案例都 ~U ≤ W
cor(notU, cv$W)          # 0.766：相關並不完美

# 圖 2-1：XY 圖（充分性：點應在對角線上方）
XYplot(notU, cv$W, relation = "sufficiency")

# 條件組合：I·~U
XYplot(fuzzyand(cv$I, notU), cv$W, relation = "sufficiency")

XYplot() 會在圖上同時印出一致性與覆蓋度（第 3 章的主題）。若想直接取得這些數字，可用 pof(notU, cv$W, relation = "sufficiency")；R 的完整操作可參考本站主教材〈Ch.4 模糊集 fsQCA〉。

7. 本章重點、名詞與自我測驗 · Review

  1. 模糊集讓案例可以部分隸屬於集合（0 到 1 之間），同時保留子集合、交集、聯集等集合論運算。
  2. 三個定性錨點：1 = 完全隸屬、0.5 = 交叉點（最模糊）、0 = 完全不隸屬；> 0.5 偏在內、< 0.5 偏在外。
  3. 模糊集不是定序量表或一般變數：分數必須以理論與實質知識對照集合定義來校準；依最小–最大值或排名機械換算是嚴重錯誤。
  4. 錨點區分相關與無關的變異；換了集合的概念（如「富裕」→「中等收入」），同一指標的隸屬分數就會改變。
  5. 三種運算：否定 ~X = 1 − X；交集 X·Y = min；聯集 X + Y = max。
  6. 模糊子集關係：所有案例 X ≤ Y → X ⊆ Y。XY 圖中點都在對角線上或左上方；右下三角形對應清晰集的格 4。
  7. 左上方的點不是誤差，而是其他路徑的線索；集合關係可以完美成立，即使 r 只有 0.766。

自我測驗

某國在「民主國家」集合的隸屬分數是 0.3。這代表什麼？

0.3 在 0 與 0.5 之間：偏在集合外，但不是「完全不隸屬」（那是 0）。

美國在「高製造業就業」集合（M）的分數是 0.4，它在 ~M 中的分數是？

否定：~M = 1 − M = 1 − 0.4 = 0.6。

某國 A = 1.0、~M = 0.6。它在 A·~M 的隸屬分數是？

「·」是交集，取最小值：min(1.0, 0.6) = 0.6。不是相乘，也不是平均。

某國 A = 0.2、~M = 0.8。它在 A + ~M 的隸屬分數是？

「+」是聯集，取最大值：max(0.2, 0.8) = 0.8。

「X 是 Y 的模糊子集合」的判準是？

模糊子集關係要求逐案 Xi ≤ Yi；在 XY 圖上，所有點都在對角線上或其左上方。

在圖 2-1 中，愛爾蘭（~U = 0.2、W = 0.8）落在左上方。正確的解讀是？

左上方的點符合子集關係。條件分數低、結果分數高，表示有「別條路」通往結果。只有右下方的點才違反充分性型態的子集關係。

圖 2-1 的 Pearson r = 0.766。從集合論的角度，這些資料對「非強大工會 ⊆ 弱階級投票」來說是？

集合關係是非對稱的：12 國全部 ~U ≤ W，集合關係完美成立。r 不完美是因為左上方的點（愛爾蘭、比利時等）拉低了相關。

要把一個六級的國家財富定序量表轉成「富裕國家」模糊集，正確的做法是？

定序類別只是相對排序；轉成隸屬分數必須看類別的實質內容是否符合集合的定義。機械換算、依排名、或用樣本平均數當交叉點都缺乏理論依據。
