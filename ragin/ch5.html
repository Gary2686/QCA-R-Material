1. 把定距變數轉為模糊集：三種尺度 · Converting interval-scale variables to fuzzy sets

第 4 章說過：傳統變數要嘛沒有校準，要嘛只靠樣本平均數與標準差做了「隱性」校準——換一個樣本，標準就跟著變。模糊集則必須用外部標準來校準，而這些標準要符合研究者對目標集合的概念化、定義與命名。

理想上，「人均所得多少才算完全屬於已開發國家」應該由學界累積的實質知識決定。Ragin 坦白承認：這樣的共識知識庫目前並不存在，部分原因是變數導向研究只在乎「離平均數多遠」，很少有人認真討論門檻。但他也強調，這不是什麼艱難任務，只需要研究者持續關注實質問題（例如：什麼樣的國家才算完全已開發？）。所以本章的重點是校準技術，錨點的具體數值只是示範。

ℹ️ 本章方法的兩個前提

① 你手上已經有一個定距或定比尺度的指標，例如用人均國民所得（GNP per capita）衡量發展。
② 你的概念可以用集合來命名，例如「已開發國家集合」。注意這個命名會把研究拉向案例導向：「已開發國家」指向一群具體的國家，而「發展程度」只是國家間變異的一個向度。

同一個數字的三種寫法

直接法的訣竅是借用一個中間尺度：對數勝算（log odds，簡中譯本稱「對數概率」）。三種尺度的換算如下：

隸屬度 → 勝算 → 對數勝算 勝算 = 隸屬度1 − 隸屬度　　log odds = ln(勝算)
反過來：對數勝算 → 隸屬度 隸屬度 = exp(log odds)1 + exp(log odds)

  • 以 0 為中心完全對稱：+2 與 −2 分別代表「相當隸屬」與「相當不隸屬」，距離交叉點一樣遠。

⚠️ 模糊隸屬分數不是機率

雖然公式長得像 logistic 迴歸，但 0～1 的隸屬分數代表的是一個命題的真值（truth value），而不是事件發生的機率（probability）。Ragin 的例子：「啤酒是致命毒藥」這個命題的真值大約是 0.05——幾乎（但不完全）不屬於「真命題」集合。如果把它讀成機率，就變成「每 20 瓶啤酒就有 1 瓶會毒死人」，那每天暢飲啤酒的數百萬人早就出事了。

2. 直接校準法 · The direct method

任何校準的起點，都是把目標集合說清楚。這裡的目標集合是「已開發國家」，原始資料是 136 國的人均國民所得；原書表 5-2 列出其中 24 國作示範。

直接法用三個定性錨點（qualitative anchors）來建構校準（參見第 2 章）：

錨點Ragin 的設定（人均所得）對應 log odds對應隸屬度
完全隸屬門檻（full membership）20,000 美元+3≈ 0.95
交叉點（crossover point）5,000 美元00.50
完全不隸屬門檻（full non-membership）2,500 美元−3≈ 0.05

交叉點是「最模糊」的位置：剛好在這裡的案例，既說不上在集合內、也說不上在集合外。所得 ≥ 20,000 的國家視為完全屬於已開發國家（隸屬度 ≥ 0.95）；所得 ≤ 2,500 的國家視為完全不屬於（隸屬度 ≤ 0.05）。

📌 為什麼門檻是 0.95 而不是 1.0？

因為用 log odds 計算，隸屬度永遠不會剛好等於 1.0 或 0.0（那需要正負無限大）。所以 Ragin 約定：高於 0.95 就當作（幾乎）完全隸屬，低於 0.05 就當作（幾乎）完全不隸屬。表格中出現的 1.00、0.00 只是四捨五入的結果。

四個步驟

算偏離值：原始值 − 交叉點

以交叉點為中心重新定位。正值＝偏向隸屬，負值＝偏向不隸屬。例如阿根廷 7,470 − 5,000 = 2,470。

選標量（scalar）

交叉點上方：標量 = 3 ÷（完全隸屬門檻 − 交叉點）= 3 / 15,000 = 0.0002。
交叉點下方：標量 = −3 ÷（完全不隸屬門檻 − 交叉點）= −3 / −2,500 = 0.0012。

相乘得到 log odds

偏離值 × 標量。阿根廷：2,470 × 0.0002 = 0.494。這一步把「所得」重新刻度成「屬於已開發國家的對數勝算」。

換回隸屬度

exp(0.494) / (1 + exp(0.494)) = 0.62。阿根廷「有點屬於」已開發國家。

你可以把這套程序想像成：在「偏離值—log odds」平面上畫兩條斜率不同的直線，都從原點 (0, 0) 出發，一條通往 (15,000, 3)，一條通往 (−2,500, −3)；兩個標量就是這兩條線的斜率。下方的 S 形曲線，就是把這條「折線」經過 exp/(1+exp) 彎曲後的樣子。

直接法的完整公式 log odds = (x − 交叉點) × ±3錨點 − 交叉點　→　隸屬度 = elog odds1 + elog odds

3. 間接校準法 · The indirect method

直接法需要你精確說出三個數值；間接法則只要求你把案例大致分組。做法是：先依案例在目標集合中的「推定隸屬程度」做定性分組，給每組一個初步分數，再用原始的定距數據去修飾（refine）這些分數。

Ragin 使用六個定性類別（其他編碼方案也可以，只要至少有三類；重點是分組必須反映研究者對每個案例的初步判斷，並盡可能以理論與實質知識為依據）：

定性類別完全隸屬相當隸屬有點隸屬有點不隸屬相當不隸屬完全不隸屬
初步分數1.00.80.60.40.20.0

原書表 5-4 的分組，刻意沿用直接法的大致標準（所得超過 20,000 編為完全隸屬、超過 5,000 編為偏隸屬……），方便比較兩種方法。

定性分組

依實質知識把每個案例放進六類之一，並給初步分數（1.0, 0.8, …, 0.0）。這些分數是「粗略估計」，可以修改。

以原始指標預測分組分數

以人均所得為自變數、定性分數為依變數，做分數 logit 模型（fractional logit）。因為依變數介於 0～1，用 logit 連結函數最合適。Ragin 在 Stata 用分數多項式（fractional polynomial）迴歸：fracpoly glm qualcode intervv, family(binomial) link(logit)，再用 predict 取得預測值。

預測值就是校準後的隸屬分數

預測值會自動落在 0～1，且隨所得平滑變化；它結合了所得（定距資訊）與定性分組（外部知識）。Ragin 的預測值是用全部 136 國估計的，不只表中的 24 國。

兩種方法的比較

比較表 5-2（直接法）與表 5-4（間接法），兩者整體非常相似，但有兩個重要差異：

  1. 完全隸屬的位置不同：直接法忠實地把 20,000 美元當作 0.95 的門檻；間接法的 0.95 門檻則落在低得多的所得水準。
  2. 差距被放大或縮小：間接法中，土耳其（0.397）與下一個國家玻利維亞（0.053）之間有很大落差；直接法中兩者只是 0.08 與 0.01。

這些差異來自間接法本身的「間接性」，以及它必須依賴迴歸估計。不過，如果研究者說不出直接法所需的精確錨點，兩表的相似性證明：間接法同樣能產生有用的隸屬分數。

直接法

  • 你要能精確說出三個數值錨點
  • 完全透明：任何人都能用同樣錨點重算
  • 曲線形狀固定（log odds 上是兩段直線）

間接法

  • 只需把案例粗分成幾組（至少三類）
  • 分組判斷越有實質依據，校準越精確
  • 曲線形狀由資料決定，受迴歸模型設定影響

4. 使用已校準的測量 · Using calibrated measures

校準好的模糊集最大的用途，是檢驗用集合關係表達的理論。第 1 章提過：多數社會科學理論是文字理論，而文字理論幾乎都是集合陳述。例如「已開發國家是民主國家」，意思是「已開發國家集合」是「民主國家集合」的子集合——就像「烏鴉是黑的」把子集合放在句首一樣。

這個子集合關係可對應到一種因果論證：發展是民主的充分（但非必要）條件。有發展就應該有民主；但沒有發展卻有民主的案例並不推翻這個論點（只會拉低相關），因為通往民主還有其他路徑，例如由前殖民母國強加的民主體制。

ℹ️ 為什麼要模糊集，而不是二分法？

在模糊集出現之前（Zadeh 1965 等），想用集合方法檢驗這類命題，就得把所得硬切成「已開發／未開發」兩類。這常被批評：研究者可能挑一個對自己論點最有利的切點。校準後的模糊隸屬分數避開了任意的二分，使集合分析變得可行且可信。

模糊子集合的一致性

在模糊集中，X ⊆ Y 的意思是：每個案例在 X 的隸屬度都小於或等於它在 Y 的隸屬度（第 2 章）。現實資料很少完美，所以用第 3 章的一致性公式衡量「有多接近」：

充分性一致性（Consistency） Consistency(Xi ≤ Yi) = Σ min(Xi, Yi)Σ Xi

用相關方法評估集合論點的三個困難

  1. 集合命題談的是案例類別，相關談的是變數。「已開發國家是民主國家」關心的是一類案例；相關係數只關心變異向度。極端地說，一份資料可能根本沒有任何已開發或民主國家，研究者照樣能算出發展與民主的相關——但這份資料完全無法檢驗那個命題。
  2. 相關是對稱的，集合論點幾乎都是不對稱的。許多未開發國家也是民主國家，會削弱相關，但不會削弱「已開發 ⊆ 民主」的一致性。這個理論只對已開發國家下斷言，並沒有說未開發國家與高度開發國家的民主程度差多少。
  3. 相關對研究者的校準不敏感。在全部 136 國中，「已開發」與「至少中等已開發」兩個模糊集的 Pearson 相關高達 0.911——從相關的角度看幾乎沒差；但從集合論看差很多（覆蓋度 0.35 vs. 0.52）。原因是相關依賴「離平均數多遠」，而平均數是從樣本歸納出來的。

想一想：為什麼「更包容的條件集合」是更嚴格的充分性檢驗？

充分性要求每個案例 Xi ≤ Yi。條件集合越包容，Xi 普遍越大，越容易「超過」Yi，違反子集合關係的機會越多。例如土耳其在「已開發」只有 0.08，幾乎不可能違反；但在「至少中等已開發」有 0.57，如果土耳其的民主隸屬度低於 0.57，就會扣一致性分數。所以「至少中等已開發 ⊆ 民主」仍有 0.95 的一致性，是比 0.99 更有力的證據。

5. 結論 · Conclusion

本章展示了模糊集的力量，以及校準對有效使用模糊集的重要性。未校準的測量只能告訴你「多一點／少一點」；校準後的測量還能告訴你「多很多還是少很多」——也就是相對於有意義門檻的位置。

  • 校準讓社會科學扎根於實質知識，也讓研究結果與實務、政策問題更相關。模糊集是校準特別好用的載體，它超越了量化與質化的二分。
  • 量化社會科學目前的做法削弱了對校準的關注：指標式測量只需要「案例之間有變異」，並把所有變異視為同樣重要；而相關方法又依賴離均差，常常抵消研究者所做的任何直接校準。
  • 如果承認多數社會科學理論本質上是集合論的、而相關方法不能評估集合關係，研究者就必須忠於理論：清楚界定與核心概念對應的目標集合，並指定可以指導校準的外部標準。不經仔細校準就做集合分析，是徒勞的。

6. 實用附錄：在 fsQCA／R 中校準 · Practical appendix

⚠️ 最常見的坑：兩套軟體的錨點順序相反

fsQCA：calibrate(x, 完全隸屬, 交叉點, 完全不隸屬)（由高到低）
R 的 QCA 套件：thresholds = c(完全不隸屬, 交叉點, 完全隸屬)（e, c, i，由低到高）

準備資料

在 fsQCA 建立或開啟資料集；SPSS、Excel 資料請存成逗號或 Tab 分隔檔，第一列放簡單的變數名稱。缺失值留白，不要用 −999 之類的特殊代碼。

開啟計算視窗

在資料表視窗點選 Variables → Compute。

命名新的模糊集

取一個 2～8 個字元的簡單名稱（例如 fdev），只用英文字母與數字，不要有空格、破折號或標點。

插入 calibrate 函數

在函數清單中點選 calibrate(x,n1,n2,n3)，再按函數按鈕旁的向上箭頭，運算式欄會出現 calibrate(,,,)。

填入變數與三個錨點

改成例如 calibrate(gnpcap, 20000, 5000, 2500)：第一個數字是完全隸屬門檻（0.95），第二個是交叉點（0.5），第三個是完全不隸屬門檻（0.05）。

按 OK 並檢查

點選某欄後用 Cases → Sort Ascending（或 Descending）排序，對照原始變數與新的模糊分數，確認結果符合你的預期。

直接法：QCA 套件的 calibrate()，type = "fuzzy"（預設即為 logistic 函數，對應 Ragin 的 log odds ±3 設定）。

library(QCA)
# 原書表 5-2 的 24 國（人均國民所得，美元）
gnp <- c(40110, 34400, 25200, 24920, 20060, 17090, 15320, 13680,
         11720, 11290, 10940, 9800, 7470, 4670, 4100, 4070,
         3740, 3690, 3590, 2980, 1000, 650, 450, 110)

# 已開發國家：thresholds 依序為 e（完全不隸屬）, c（交叉點）, i（完全隸屬）
dev <- calibrate(gnp, type = "fuzzy",
                 thresholds = c(2500, 5000, 20000))
round(dev, 2)   # 1.00 1.00 0.98 0.98 0.95 0.92 0.89 0.85 ... 0.08 0.01 0.01 0.00 0.00

# 也可以寫成具名字串，比較不會弄錯順序
mod <- calibrate(gnp, type = "fuzzy",
                 thresholds = "e=1000, c=2500, i=7500")   # 表 5-3

# 手動驗算（與 Ragin 的四步驟完全相同）
dev_by_hand <- function(x, i, c, e) {
  d  <- x - c
  lo <- ifelse(d >= 0, d * 3 / (i - c), d * -3 / (e - c))
  exp(lo) / (1 + exp(lo))
}
all.equal(dev, dev_by_hand(gnp, 20000, 5000, 2500))

# 兩個集合的相關 vs. 平均隸屬度（呼應第 4 節）
cor(dev, mod); mean(dev); mean(mod)

間接法：先依實質知識給定性分數，再用分數 logit（quasibinomial GLM）預測。以下用 ln(所得) 作預測式；Ragin 原本用的是 Stata 的分數多項式，形式更有彈性。

# 原書表 5-4 的定性編碼（六類：1, .8, .6, .4, .2, 0）
qual <- c(1,1,1,1,1, .8,.8,.8,.8,.8,.8, .6,.6,
          .4,.4,.4, .2,.2,.2,.2, 0,0,0,0)

fit <- glm(qual ~ log(gnp), family = quasibinomial(link = "logit"))
dev_ind <- predict(fit, type = "response")   # 間接法的模糊隸屬分數
round(cbind(gnp, qual, direct = dev, indirect = dev_ind), 3)

7. 本章重點、名詞與自我測驗 · Review

  1. 模糊集必須用外部標準校準，標準來自研究者對目標集合的概念化與實質知識，而不是樣本平均數與標準差。
  2. 隸屬度、勝算、log odds 是同一數值的三種寫法；log odds 以 0 對稱、無上下限，換回隸屬度永遠在 0～1 之間。
  3. 直接法：三錨點對應 log odds +3／0／−3（≈ 0.95／0.5／0.05）；偏離值 × 上方或下方標量 = log odds，再用 exp/(1+exp) 換回隸屬度。
  4. 目標集合變了（已開發 → 至少中等已開發），錨點就要變；同一個土耳其可從 0.08 變成 0.57。
  5. 間接法：先依知識把案例分成六類（1, .8, .6, .4, .2, 0），再以原始指標做分數 logit 迴歸，預測值即為隸屬分數。
  6. 校準後的集合可用一致性與覆蓋度檢驗集合論命題；兩個集合即使相關高達 0.911，集合論結論仍可能差很多——相關對校準不敏感。
  7. fsQCA 的 calibrate(x, 完全, 交叉, 不隸屬) 與 R 的 thresholds = c(e, c, i) 順序相反。

自我測驗

在直接法中，「完全隸屬門檻」對應的 log odds 是 +3，換成隸屬度大約是？

exp(3) = 20.09，20.09 / 21.09 ≈ 0.953。隸屬度永遠到不了 1.0，所以 Ragin 以 0.95 作為「（幾乎）完全隸屬」的門檻。0.881 是 log odds = 2。

「已開發國家」的錨點為 20,000／5,000／2,500 美元。交叉點下方案例使用的標量是？

下方標量 = −3 ÷（2,500 − 5,000）= −3 / −2,500 = 0.0012，是正數；乘上負的偏離值後得到負的 log odds。0.0002 是上方標量，0.0006 是表 5-3 的上方標量。

同樣的錨點下，人均所得剛好 5,000 美元的國家，在已開發國家集合的隸屬度是？

5,000 就是交叉點，偏離值 = 0 → log odds = 0 → 隸屬度 = 0.5，最模糊的位置。0.62 是阿根廷（7,470 美元）。

土耳其在表 5-2 的隸屬度是 0.08，在表 5-3 卻是 0.57。主要原因是？

兩表使用同一份所得資料、同一種直接法。差別只在外部標準：表 5-3 的交叉點是 2,500，土耳其的 2,980 已在交叉點之上。這正說明校準依賴知識與概念定義。

間接校準法的第一個、也是最重要的步驟是？

間接法的外部標準就是研究者對案例的定性評估（例如六類：1, .8, .6, .4, .2, 0）；之後才用迴歸把原始指標調整到符合這些評估。指定三個數值是直接法。

「啤酒是致命毒藥」這個命題的模糊隸屬分數約 0.05，正確的讀法是？

模糊隸屬分數是真值，不是機率。把 0.05 讀成機率會得出荒謬結論。

「已開發」與「至少中等已開發」兩個模糊集的相關高達 0.911，但對民主國家的覆蓋度分別是 0.35 與 0.52。這說明了什麼？

相關依賴樣本的離均差，會抵消直接校準的效果；而集合論的一致性、覆蓋度直接使用隸屬分數，對校準高度敏感。

在 fsQCA 中輸入 calibrate(intvar, 25, 10, 2)，三個數字依序代表？

fsQCA 由高到低：完全隸屬、交叉點、完全不隸屬。R 的 QCA 套件 thresholds 則是 e, c, i 由低到高，寫成 c(2, 10, 25)。
