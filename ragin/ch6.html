1. 組態思維與案例導向研究 · Configurational thinking and case-oriented research

組態（configuration）指的是一組條件同時出現的特定組合。質性研究者特別習慣用組態來思考，因為他們重視情境，喜歡把一個社會現象當作一個整體來理解；他們想知道的往往不是「哪個因素影響最大」，而是「事情如何發生」。從配方的角度思考，就是把相關的條件看成一起推動事件發生的力量的交集。

例子：秘魯的反緊縮抗議

Ragin 用一個案例研究說明。假設一位研究者主張：1980 年代秘魯之所以爆發大規模抗議、反對國際貨幣基金組織（IMF）要求的緊縮計畫，是因為以下四個條件同時成立：

代號條件性質
AIMF 緊縮措施很嚴厲（Austerity）短期、事件性的條件
S窮人高度集中在都市貧民窟（Slums）長期、結構性的條件
P民眾感受到政府官員腐敗（Perceived corruption）認知、政治性的條件
M近期有大量政治動員與抗爭的歷史（Mobilization）歷史性的條件

這個解釋有典型的「配方」性格：它混合了長期條件與短期條件，四者在秘魯剛好湊齊，才共同解釋了抗議的爆發。

🔑 案例研究的論點幾乎都是「非對稱」的

秘魯的配方解釋的是「抗議為什麼發生」，不是「所有反緊縮抗議的完整解釋」，也不是「抗議為什麼沒發生」。其他國家的抗議很可能來自別的配方，所以就算很多抗議案例沒有秘魯的四條件組合，也推翻不了「秘魯配方是大規模抗議的充分（但非必要）組合」這個主張。反過來說，政府若只避開秘魯這個組合，也不保證就不會有抗議。

從秘魯出發的兩條研究路線

研究者手上有秘魯這個案例之後，可以往兩個方向擴展，它們正好對應第 1 章的兩種集合論策略：

路線一：從「結果」選案例

  • 找其他發生了反緊縮抗議的國家
  • 問：它們是不是全都（或幾乎都）具備這四個條件？
  • 集合關係：結果 ⊆ 配方 → 檢驗必要性

這就是常被量化研究者批評的「依依變數選樣」——但在集合論邏輯下，它是正當的研究設計。

路線二：從「配方」選案例

  • 找其他同樣湊齊四個條件的國家
  • 問：它們是不是全都（或大多）爆發了抗議？
  • 集合關係：配方 ⊆ 結果 → 檢驗充分性

這裡的「自變數」不是單一變數，而是整個配方。

兩條路線可以並用。若兩種子集合關係同時成立，「秘魯配方的案例」和「抗議案例」兩個集合就會重合。這看起來很像相關分析，但請回想第 1 章：相關要高，還需要大量「既沒有配方、也沒有抗議」的（0, 0）案例；而上面兩條路線都不直接依賴這類案例。

📌 組態思維最重要的特徵：直接連回案例

「某個條件組合產生某結果」的論點，指向具體的案例以及這些案例的具體特徵。因果關係最終只能在案例層次觀察到；一個配方會清楚告訴你：到案例裡該去看什麼、該去追哪一段因果過程與機制。也因此，配方本身必須內在一致、說得通——它要像一道合理的食譜，而不是一串隨意湊合的材料。

2. 組態與傳統定量分析 · Configurations and conventional quantitative analysis

傳統定量研究把每個自變數看成各自獨立影響依變數的原因。多數應用假設效果是線性且可加（linear and additive）的：不論其他變數取什麼值、怎麼組合，某個自變數的效果都一樣。這就是淨效應（net effect）的意思。

要估計淨效應，迴歸會把每個變數與其他變數「共同解釋」的那部分變異扣掉，只留下它不重疊的貢獻。重疊多少取決於自變數之間的相關：某變數與其他競爭變數越相關，它的淨效應就越小。換句話說，在這個框架下，自變數彼此是在搶解釋力。

標準建議：加交互作用項

如果理論說「條件要組合在一起才有用」，教科書的標準建議是加入交互作用項（interaction term），例如 A×P，再檢定它是否顯著增加解釋力。交互作用的意思是：緊縮（A）對抗議的影響大小，取決於腐敗感知（P）的程度——也許腐敗讓緊縮的社會後果更具爆炸性。

問題是，為「線性可加模型」設計的估計技術，拿來估計複雜交互作用時往往捉襟見肘：

  1. 資料需求暴增：要估秘魯那種四個條件的四階交互作用，模型需要的項數與案例數會急遽膨脹（見下方互動）。
  2. 變數缺乏有意義的零點：乘積項 A×P 的意義會隨變數的量尺原點改變（例如把變數平移、中心化後，主效應的係數就整個變了），解讀爭議很多（Allison, 1977）。
  3. 難以表達「多個配方」：專門估計淨效應的工具，本來就不擅長評估配方；若結果有好幾條不同的配方路徑，更是難上加難。

3. 評估案例在組態中的隸屬度 · Assessing membership in configurations

Ragin 提出一個關鍵的轉念：與其在線性模型裡檢定交互作用，不如把組態問題當成測量問題——直接算出「這個配方在這個案例中被滿足到什麼程度」，也就是案例在配方上的隸屬度。模糊集正好適合做這件事。

交集 = 取最小值：「最弱環節」原則

在模糊集中，案例隸屬於一個條件組合的程度，等於它在各構成條件中的最低分。這就是「最弱環節（weakest link）」的觀點：一條鏈子的強度取決於最弱的那一環；一個案例符合配方的程度，也取決於它最不符合的那個條件。

案例 i 在秘魯四條件配方中的隸屬度（模糊集交集，邏輯 AND） Ri = min( Ai, Si, Pi, Mi )

前提是：所有條件都已經用相同方式校準成 0（完全不隸屬）到 1（完全隸屬）的模糊集（見第 5 章）。公式要對每個案例分別計算。

否定 = 1 − 隸屬分數

配方裡也可能需要某條件「不存在」，例如「嚴厲緊縮 × 沒有腐敗感知」。模糊集的否定（negation）很簡單：案例在「非 P」（記為 ~P）中的隸屬度 = 1 − P。算好否定後再一起取最小值即可（第 2 章已介紹這些模糊代數）。

例：配方 A·~P 的隸屬度 min( Ai, 1 − Pi )
✍️ 逐步算一次

某國：A = 0.90、S = 0.70、P = 0.40、M = 0.80。

① 四條件配方 A·S·P·M：min(0.90, 0.70, 0.40, 0.80) = 0.40，最弱環節是 P（腐敗感知）。此國「比較不在」秘魯配方裡（低於 0.5 的交叉點）。

② 拿掉 P 的三條件配方 A·S·M：min(0.90, 0.70, 0.80) = 0.70，最弱環節換成 S。

③ 配方 A·~P：~P = 1 − 0.40 = 0.60，min(0.90, 0.60) = 0.60。

想一想：為什麼不用「平均」或「乘積」來代表配方隸屬度？

平均允許「互相補償」：緊縮很嚴厲（1.0）可以抵銷完全沒有腐敗感知（0.0），平均 0.5——但配方的意思是缺一不可，缺了 P 這個配方就不成立，補償違反配方邏輯。

乘積不允許補償，但它會隨條件數機械式縮水：四個條件都是 0.8 的案例，乘積只剩 0.41，好像它「不太在」配方裡；用最小值則是 0.8，忠實反映「每個條件都相當程度地成立」。這也是迴歸交互作用項（乘積）與集合交集在精神上的根本差異。

算出每個國家在秘魯配方中的隸屬度後，就能拿它與結果（在「大規模反 IMF 抗議」集合中的隸屬度）比較。如果秘魯配方是好幾條路之一（充分但非必要），那麼符合配方的案例應該是抗議案例的子集合：在以抗議為 Y 軸、配方為 X 軸的 XY 圖上，點應該集中在對角線上方的左上三角形。

4. 比較前因配方 · Comparing causal recipes

用模糊集處理配方非常靈活：要提出並比較競爭的配方，或比較簡單與複雜的組合，都只是多算幾欄最小值的事。例如另一位研究者認為腐敗感知（P）並非必需，主張較簡單的三條件配方：

去掉 P 的三條件配方 Ri = min( Ai, Si, Mi )

一個必然成立的數學性質

三條件配方是四條件配方的簡化，所以是更具包容性的組合。因為多取一個條件的最小值只可能讓分數持平或變低，每個案例在四條件配方中的隸屬度一定 ≤ 在三條件配方中的隸屬度。從集合論來看：往交集裡多加一個集合，產生的是原交集的子集合。

條件越多（越複雜）

  • 隸屬分數越低（X 變小）
  • 點往左移 → 較容易落在對角線上方
  • 一致性通常 ↑
  • 覆蓋度必然 ↓（或持平）

條件越少（越簡單）

  • 隸屬分數越高（X 變大）
  • 點往右移 → 較可能跑到對角線下方
  • 一致性通常 ↓
  • 覆蓋度必然 ↑（或持平）

這就是第 3 章所說的一致性與覆蓋度之間的此消彼長。覆蓋度的方向是數學上必然的（分子 Σmin(X,Y) 會隨 X 變小而不增，分母 ΣY 不變）；一致性的方向則只是「通常如此」——Ragin 在註腳中指出，可以造出簡單配方一致性反而較高的資料，只是實際上很少見。

⚠️ 先看一致性，再看覆蓋度

一致性回答「這個配方是不是結果的子集合」；只有在一致性夠高時，覆蓋度（「這個配方解釋了多少結果」）才有意義。一致性低的配方即使覆蓋度很漂亮，也只是「涵蓋很多案例，但不是穩定的充分路徑」。

從一個完整配方延伸出 15 個版本

這套程序可以推廣：以四條件配方為起點，它所有非空的條件子集合共有 15 個——1 個四條件、4 個三條件、6 個兩條件、4 個單條件（24 − 1 = 15）。對每一個都算隸屬度、一致性與覆蓋度，就能系統地比較簡化版與完整版。原則是：

🔑 選擇配方的兩條原則

① 簡單配方的一致性若跟複雜配方差不多，覆蓋度又明顯較大，就選簡單的。（例：A·P 的 0.90／0.71 勝過 A·S·P·M 的 0.93／0.53）

② 但不要為簡約而簡約。如果四條件配方是 0.93／0.80、三條件是 0.91／0.81，差異微不足道。追求簡約的科學習慣會偏好三條件，但從組態角度看，四條件配方可能更完整地連結到觀察到的因果過程、更有助理解因果機制——分數相近時，有實質與理論依據的較複雜解釋可能更好。

想一想：能不能對一致性做統計檢定？

可以。一致性是一個比例，所以能套用比例的機率檢定。Ragin（2000）的做法是：計算前先設定基準一致性與 α 水準，再檢定觀察到的一致性是否顯著高於基準。

例如書中的問題：「有 50 個案例、α = 0.05，觀察到 0.93 是否顯著高於 0.75？」用常態近似：z = (0.93 − 0.75) / √(0.75 × 0.25 / 50) ≈ 2.94，單尾 p ≈ 0.002，答案是「是」。同樣的方法也能比較兩個一致性、或兩個覆蓋度。不過本章的重點是描述性地理解一致性與覆蓋度。

📌 最後的考驗永遠在案例裡

任何配方真正的試金石，是它能否和案例資訊產生共鳴。集合論分析很重要的一步就是回到案例：配方指出了該在哪些案例裡、找哪些特徵與因果過程。當研究的產出是「前因配方」而不是「自變數的淨效應」時，分析結果與實際案例之間的連結會強得多——這也讓「跨案例分析」與「案例內分析」能夠對話。

5. 實用附錄：如何評估前因配方 · Practical appendix: assessing causal recipes

當你心中有一個特定配方，或想比較幾個配方的一致性與覆蓋度時，流程是：定義配方 → 把每個條件校準為模糊集（第 5 章）→ 用交集算出配方隸屬度 → 用 XY 圖與一致性／覆蓋度評估它與結果的集合關係。

定義配方

決定配方由哪些條件（成分）組成，例如四個條件 A、S、P、M。目標是評估每個案例符合這個特定組合的程度。

把每個條件校準為模糊集

必要時用第 5 章的直接校準法，把等距／比率尺度的原始變數轉成 0–1 的模糊集。

開啟計算對話框

匯入資料後，在資料試算表視窗點 Variables → Compute，出現 Compute Variable 對話框。為新變數命名：用 2–8 個英數字元、不要空格、破折號或標點，例如 recipe1。

插入 fuzzyand()

在函數清單中點 fuzzyand(x,...,)，再按 Functions 旁的向上箭頭，它就會出現在運算式欄位。fuzzyand 執行模糊集交集：對每個案例取括號內各集合的最小隸屬分數。

編輯運算式後按 OK

改成 fuzzyand(A, S, P, M)（用你資料檔中的模糊集變數名）。若某條件要取否定，可先用 fuzzynot(P) 另算一欄（或直接計算 1 − P），再放進 fuzzyand。

檢查結果

回到資料試算表確認新欄位是否如預期。點新欄位任一格，再用 Cases → Sort Ascending / Descending 排序，快速看看哪些案例最符合配方。

畫 XY 圖

點 Graphs → Fuzzy → XY Plot（新版為 Graphs → XY Plot）。Y 軸選結果的模糊集，X 軸選剛算出的配方隸屬度；可另指定 Case Id 變數，以辨識圖上的點是哪個案例。

按 Plot 並解讀

若預期配方是「充分但非必要」，點應落在主對角線上或上方。圖左上角方框的數字是子集合關係 Xi ≤ Yi 的一致性；右下角方框的數字是配方對結果的覆蓋度。

以下用本章自建的假想資料（19 國）示範。fuzzyand()、fuzzyor() 是 QCA 套件提供的交集／聯集函數；compute() 可直接計算一個布林運算式（* = AND、~ = 否定）；pof() 回報一致性（inclS）與覆蓋度（covS）。

library(QCA)

# 假想資料：A 緊縮、S 貧民窟、P 腐敗感知、M 動員史、Y 大規模抗議
dat <- data.frame(
  A = c(.92,.85,.51,.95,.62,.94,.85,.81,.97,.80,.57,.15,.62,.02,.12,.07,.60,.74,.55),
  S = c(.04,.70,.83,.59,.77,.88,.92,.78,.99,.86,.72,.04,.38,.40,.03,.35,.04,.78,.10),
  P = c(.70,.90,.49,.86,.95,.93,.13,.87,.22,.84,.49,.55,.07,.01,.62,.70,.02,.05,.42),
  M = c(.75,.24,.66,.91,.80,.90,.88,.95,.98,.95,.81,.33,.45,.12,.55,.21,.40,.75,.30),
  Y = c(.99,.99,.99,.97,.97,.99,.88,.88,.75,.59,.36,.15,.09,.02,.02,.02,.02,.03,.12),
  row.names = sprintf("C%02d", 1:19)
)

# 1. 交集（最小值）：三種等價寫法
dat$R4 <- fuzzyand(dat$A, dat$S, dat$P, dat$M)
dat$R4 <- pmin(dat$A, dat$S, dat$P, dat$M)       # base R
dat$R4 <- compute("A*S*P*M", data = dat)
dat$R3 <- compute("A*S*M", data = dat)

# 2. 否定 = 1 - x
dat$AnP <- fuzzyand(dat$A, 1 - dat$P)            # 等同 compute("A*~P", data = dat)

# 3. 最弱環節：每個案例是被哪個條件「卡住」？
colnames(dat[, c("A","S","P","M")])[apply(dat[, c("A","S","P","M")], 1, which.min)]

# 4. 一致性與覆蓋度（充分性）
pof("A*S*P*M", outcome = "Y", data = dat, relation = "sufficiency")  # inclS ≈ 0.93, covS ≈ 0.53
pof("A*S*M",   outcome = "Y", data = dat, relation = "sufficiency")  # inclS ≈ 0.79, covS ≈ 0.67
pof("A*P",     outcome = "Y", data = dat, relation = "sufficiency")  # inclS ≈ 0.90, covS ≈ 0.71

# 5. XY 圖（X = 配方隸屬度、Y = 結果）
XYplot(dat$R4, dat$Y, xlab = "Recipe A*S*P*M", ylab = "Protest")

# 6. 一次評估 15 個子配方
conds <- c("A", "S", "P", "M")
recipes <- unlist(lapply(4:1, function(k)
  apply(combn(conds, k), 2, paste, collapse = "*")))
res <- t(sapply(recipes, function(r) {
  x <- compute(r, data = dat)
  c(cons = sum(pmin(x, dat$Y)) / sum(x),
    cov  = sum(pmin(x, dat$Y)) / sum(dat$Y))
}))
round(res, 3)

小提醒：pof() 的輸出除了 inclS（一致性）與 covS（覆蓋度），還有 PRI，這會在第 7 章談真值表時用到。想看主教材更完整的 R 操作，可參考〈Ch.4〉、〈Ch.5〉。

6. 本章重點、名詞與自我測驗 · Review

  1. 組態思維把條件看成一起產生結果的「配方」，而不是各自獨立的力量；它直接指向具體案例與因果機制，是案例導向研究的核心。
  2. 案例研究的配方論點通常是非對稱的：解釋「為何發生」，不保證「沒有這個配方就不會發生」。從結果選案例 → 檢驗必要性；從配方選案例 → 檢驗充分性。
  3. 傳統迴歸假設線性可加的淨效應，自變數之間互相「搶」解釋力；用交互作用項處理配方有三個困難：資料需求暴增、缺乏有意義的零點、難以處理多條配方路徑。
  4. Ragin 的替代方案：把組態當成測量問題。案例在配方中的隸屬度 = 各條件隸屬分數的最小值（最弱環節）；需要「不存在」的條件先取否定 1 − x。
  5. 條件越多的配方，隸屬分數只會持平或變低（是較簡單配方的子集合）→ 一致性通常較高、覆蓋度必然較低。
  6. 比較配方：簡單配方一致性相差不大、覆蓋度明顯較高 → 選簡單的；但分數差不多時，更能連結案例因果過程的複雜配方可能更好。
  7. 最後的試金石永遠是：配方能否與案例產生共鳴。

自我測驗

某案例：A = 0.8、S = 0.6、P = 0.9、M = 0.3。它在配方 A·S·P·M 中的隸屬度是？

模糊集交集取最小值：min(0.8, 0.6, 0.9, 0.3) = 0.3。最弱環節是 M（動員史）。

同一個案例（A = 0.8、P = 0.9），它在配方 A·~P 中的隸屬度是？

~P = 1 − 0.9 = 0.1；min(0.8, 0.1) = 0.1。這個案例腐敗感知很高，因此幾乎不屬於「緊縮但沒有腐敗感知」的配方。

把配方從 A·S·M 擴充為 A·S·P·M（多加一個條件），下列何者必然成立？

多取一個最小值只會讓分數持平或下降，所以四條件配方是三條件配方的子集合，覆蓋度也只會持平或下降。一致性「通常」上升，但不是必然（原書註腳指出例外存在，本章假想資料中 A·S·P 的一致性就略高於 A·S·P·M）。

研究者從秘魯案例出發，去找其他發生了反緊縮抗議的國家，檢查它們是否都具備四個條件。這是在檢驗什麼？

從結果選案例、看它們是否共享條件，是在檢驗「結果 ⊆ 配方」，也就是必要性。從配方選案例、看結果是否都出現，才是檢驗充分性。

下列哪一項不是 Ragin 指出用交互作用項處理配方的困難？

交互作用項當然算得出來；問題在於資料需求、零點的意義以及估計淨效應的工具本質上不適合評估配方，尤其是多條配方並存時。

四條件配方：一致性 0.93、覆蓋度 0.53；兩條件配方 A·P：一致性 0.90、覆蓋度 0.71。依 Ragin 的原則，較合理的判斷是？

簡單配方的一致性與複雜配方相差不大、覆蓋度又明顯較大時，簡單配方較合適。但仍要回到案例檢查它是否說得通。

四條件配方 0.93／0.80，三條件配方 0.91／0.81。Ragin 的看法是？

要避免為簡約而簡約。分數大致相同時，從組態角度看更完整、更能與案例因果過程對應的複雜配方可能更優。
