- 頁碼換算：**PDF 頁 = 中譯本書頁 + 24**。各章 PDF 範圍：序言 5–21、ch1 27–38、ch2 39–49、ch3 51–68、ch4 71–80、ch5 81–96、ch6 99–109、ch7 111–126、ch8 129–138、ch9 139–150、ch10 151–160、ch11 161–177、參考文獻 178–183。

## 製作流程（2026-10-11 第一版）
1. PDF 是掃描檔 → 用 macOS Vision OCR（Swift 小程式，`VNRecognizeTextRequest`，zh-Hans + en-US，3 倍解析度）轉文字，依上方頁碼表切章。
2. 表格／圖／公式 OCR 會亂，一律回頭看 PDF 頁面影像核對。
3. 各章所有數值用 python 重算；布林最小化結果（ch7–ch9）與 R `QCA` 3.25 比對一致。
4. 各章 R 程式碼都實際在 R（QCA 3.25）跑過，無錯誤。
5. 瀏覽器測試：12 頁自動點擊全部互動元件無 JS 錯誤、無 NaN；375px 手機寬度無水平捲軸。

## 已發現的原書誤植（頁面已加小註）
- 表 3-5：解的覆蓋度 609.709 / 1385.25 應為 0.4401，原書寫 0.4387（分子疑為 607.709）。
- 表 5-4：紐西蘭預測值 0.991 與其所得位置不符，疑誤植（頁面照錄並加黃底）。
- 表 7-3：某列 0.87，精確值 0.875；中譯本把「第 2、3 列間的落差」寫成第 3、4 列。
- 第 9 章（書頁 122）：「A·~C·~S·~R 是 ~I 的子集」漏了 ~I，應為 A·~C·~S·~I·~R。
- 第 11 章：原書說 4 條配方含父母所得，實為 3 條；表 11-1 年齡 Sig.=0.630 與 B/S.E. 不符。
- 原書「第 N 行」有時把表頭算進去（第 3、8 章），頁面改用實際列號。
