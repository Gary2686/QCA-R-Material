Easy Versus Difficult Counterfactuals

你觀察到：「天天運動、飲食清淡、不吃保健食品」的人都很健康。有人問：如果他們也吃了保健食品，還會健康嗎？大多數人會毫不猶豫地說「會」——多加一個應該有益（至少無害）的東西，不會把好結果變不見。但反過來問：「如果他們不運動，只靠飲食清淡和不吃保健食品，還會健康嗎？」這就難說了。兩個問題都在談沒有觀察到的情況，但一個「容易」回答、一個「困難」。本章要把這個直覺，變成 QCA 中處理邏輯餘項的正式工具：中間解（intermediate solution）。

1. 什麼是容易與困難的反事實 · Easy versus difficult counterfactuals

先複習第 8 章：社會現象的有限多樣性（limited diversity）讓真值表中充滿沒有案例的列，也就是邏輯餘項（logical remainders）。研究者若要用這些列來簡化結果，就得做反事實（counterfactual）的思想實驗：「如果真的有這種案例，它會出現結果嗎？」本章的關鍵問題是：哪些反事實可以放心地做、哪些需要特別論證？

情境一：加入一個「已知有幫助」的條件 → 容易

假設理論告訴我們，四個條件 A、B、C、D 都與結果 Y 有關，而且它們「存在」（而非缺席）會促成 Y。資料顯示：

觀察到的組態A·B·C·~D → Y　（有案例，且都出現 Y）

研究者懷疑真正重要的是 A、B、C，而 ~D 只是「碰巧伴隨」。要確認這點，最好的證據是一組 A·B·C·D 的案例——可惜真實世界裡沒有。於是做思想實驗：如果 A·B·C·D 存在，它會導致 Y 嗎？若答案為「會」，就能進行布林簡化：

納入反事實 A·B·C·D 之後A·B·C·~D + A·B·C·D → Y
⇒ A·B·C·(~D + D) → Y
⇒ A·B·C → Y

這個推論合理嗎？取決於既有知識。因為我們相信 D 的存在只會幫助 Y（或至少 D 的缺席不是推手），把 D 加進一個本來就已經會產生 Y 的組合，結果當然還會出現。這就是容易的反事實（easy counterfactual）：把一個多餘但有益的條件加進已知會成功的配方。

情境二：拿掉一個「已知有幫助」的條件 → 困難

現在反過來：觀察到的是 A·B·C·D → Y，研究者想主張 D 是多餘的，但 A·B·C·~D 沒有案例。要宣稱「沒有 D 也會成功」，等於從一個成功配方中移除一個理論上有貢獻的成分。這是困難的反事實（difficult counterfactual）——不是不能做，而是必須提出詳細的理論論證與經驗支持。成功做到的話，往往能帶來重要的理論洞見。

容易反事實

  • 觀察：A·B·C·~D → Y
  • 假想：A·B·C·D → Y？
  • 動作：加入一個已知有益的條件
  • 直覺：「多給一點好東西，不會讓好結果消失」

困難反事實

  • 觀察：A·B·C·D → Y
  • 假想：A·B·C·~D → Y？
  • 動作：移除一個已知有益的條件
  • 直覺：「少了一個關鍵成分，還能成功嗎？」需要論證
🔑 判斷規則（一句話版）

看反事實組態與觀察組態「不同的那個條件」：如果反事實把它設成理論預期會促成結果的狀態 → 容易；如果設成理論預期不利於結果的狀態 → 困難；如果理論對它沒有方向性預期 → 不能當作容易，需要另外論證。

還有三點要注意：

  • 容易／困難是連續的，不是硬性二分。一端是「把多餘的有益條件加進成功配方」，另一端是「從成功配方拿掉有貢獻的條件」。
  • 判斷依據是學術社群的知識存量，而不是研究者個人的偏好。這凸顯社會科學研究是依賴理論、具社會與集體性質的事業。
  • 傳統方法論談反事實時，多半談的是「困難」型：例如 Fearon（1996）所說的「如果 A 沒有發生，B 就不會發生」——這是在移除一個原因，且通常是單一因素、非組態的版本。
練習 容易還是困難？判斷 8 個反事實

每題都給你一個觀察到會出現結果的組態，以及一個沒有案例的反事實組態（兩者只差一個條件）。根據括號中的「既有知識」，判斷這個反事實屬於哪一類。

2. 容易反事實與 QCA：複雜／簡約連續體 · Easy counterfactuals and QCA

面對大量邏輯餘項，QCA 的使用者傳統上只有兩個選擇：

  1. 完全不用餘項：把所有餘項當成「不會出現結果」。得到複雜解（complex solution），又稱保守解（conservative solution）。缺點是可能不必要地複雜——連情境一那種顯然合理的簡化都做不到。
  2. 只要能讓結果更簡約，就使用任何餘項：得到簡約解（parsimonious solution）。缺點是會不加審查地同時納入容易與困難的反事實，可能簡約到不切實際——就像情境二那樣把 D 輕率地丟掉。

Ragin 的建議是：不要二選一，而是把這兩種解看成同一條連續體的兩個端點。兩端都建立在相同的證據上，差別只在於對反事實的容忍程度。

社會學家通常想要「中間」

Ragin 以 Barrington Moore（1966）《民主與專制的社會起源》為例：這本書比較 8 個國家的政治發展。

  • 極度複雜的解讀：8 個國家 = 8 種不同的條件組合，對應 8 種不同結果——什麼都沒簡化。
  • 極度簡約的解讀：只抓一個條件，例如「城市資產階級越強，越民主」。
  • Moore 實際給的：幾條不同的政治發展路徑，把國家分成少數幾群——這正是介於兩端之間的解。

QCA 的優勢在於：它不只能算出兩個端點，還提供了系統化建構中間解的工具。

原書表 9-1（1 = 是、0 = 否、? = 無案例的邏輯餘項）。為節省空間分成左右兩欄排列。

  • 複雜解：兩個正面列 A·B·~C·~D 與 A·B·~C·D 只差 D，合併為 A·B·~C。不用任何餘項，到此為止。
  • 簡約解：允許任何餘項，結果是 A。（檢查：A=1 的 8 列中，2 列是正面、6 列是餘項，沒有任何負面列，所以 A 可以單獨成立；而 B·~C 或 ~C 都會碰到負面列 0100、0000。）
ℹ️ 為什麼複雜解一定是簡約解的子集？

兩個解都必須涵蓋所有「Y = 是」的觀察列；簡約解只是額外把一些餘項當成正面案例來用。所以簡約解涵蓋的列，一定包含複雜解涵蓋的列——A·B·~C ⊆ A。

連續體上還有其他合法的解。規則是：必須保留簡約解中的條件（A），再從複雜解（A·B·~C）的其他條件中挑一些保留。於是得到兩個中間解：

複雜／簡約連續體（原書頁 119） A·B·~C　⊆　{ A·B　或　A·~C }　⊆　A
  • A·B（刪除 ~C）：需要假設餘項 A·B·C·D 與 A·B·C·~D 會出現 Y。這是在把 C 加進成功配方——而 C 的存在被認為有益 → 容易。
  • A·~C（刪除 B）：需要假設餘項 A·~B·~C·D 與 A·~B·~C·~D 會出現 Y。這是在從成功配方中拿掉 B——而 B 的存在被認為有益 → 困難。

「只納入容易反事實」的原則支持 A·B 為最佳中間解。有趣的是，這和傳統案例研究者會得出的結論一樣——他們關心的條件是：① 正面案例（或至少其中一群）共享的；② 被相信與結果有關的；③ 不出現在任何負面案例中的。

想一想：為什麼不能把 A 也刪掉，得到 B·~C？

因為 B·~C 會涵蓋 0100（A 缺、B 在、C 缺、D 缺），而那一列是觀察到 Y = 否的負面案例。任何解都不能涵蓋負面列——這也是為什麼簡約解的條件（A）一定要保留：中間解必須是簡約解的子集，這叫做子集原則。

Ragin 歸納出建構最佳中間解的程序：從複雜解中，刪除那些與既有知識不一致的條件；同時遵守子集原則——結果必須仍是簡約解的子集。QCA 的一大優點是：所有容易與困難的反事實都被明白寫出，納入的過程也是透明的，研究的生產者與讀者都能檢視與評估。

3. 示範：Stokke 的國際漁業「點名施壓」研究 · A demonstration

Olav Schram Stokke（2004）研究國際漁業制度中的「點名施壓（shaming）」：當某國違反國際漁業協定時，其他國家公開批評它，試圖讓它改變行為。（簡中譯本將 shame 譯為「抹黑」。）他分析了 10 次施壓，5 次成功（被批評的國家改變了行為）、5 次失敗。五個前因條件：

代號條件白話預期方向
A建議（Advice）施壓者的批評能否援引制度內科學諮詢機構的明確建議存在有利
C承諾（Commitment）被批評的行為是否明確違反制度決策機構通過的保育措施存在有利
S未來影響（Shadow of the future）被施壓者認為日後還需要在制度內談新交易，若無視批評可能受損存在有利
I不便（Inconvenience）要求對方做的行為改變，對對方而言有多不方便缺席有利
R國內反響（Reverberation）不遵守協定會在被施壓國國內引發的政治代價存在有利

兩個端點

複雜解（不用任何餘項）A·S·I·R + A·C·S·~I·~R + A·~C·~S·~I·~R → Y

32 列中只有 4 列呈現結果，而且只發生了一次簡化：A·C·S·I·R 與 A·~C·S·I·R 只差 C，合併為 A·S·I·R。

簡約解（容易與困難的餘項都用）~I + S·R → Y

意思是：當「改變行為並不麻煩」（~I），或「未來還要打交道」且「國內有反響」（S·R）時，施壓會成功。這不算不合理，但案例研究者會立刻注意到一件事：四個成功組態全都有 A（科學諮詢機構的支持）。這樣明顯的共同點——甚至可視為成功的必要條件——卻在簡約解中消失了。

註：簡中譯本頁 122 寫「A·~C·~S·~R 是 ~I 的子集」，漏了 ~I；應為 A·~C·~S·~I·~R。

逐項推導中間解

做法很機械：檢查複雜端的每一項，問「哪些條件可以刪？」每個條件只有三種命運：

  1. 它出現在對應的簡約項中 → 不能刪（否則違反子集原則）。
  2. 它的狀態符合預期方向（例如 A 存在）→ 不刪，刪掉它等於做困難反事實。
  3. 它的狀態違反預期方向（例如 I 存在、或 ~R）→ 可以刪，因為「換成有利狀態，成功案例依然會成功」——這是容易反事實。
練習 親手刪除條件，推導 Stokke 的中間解

點擊你認為可以刪除的條件。答對會劃掉（綠），答錯會告訴你為什麼不能刪（紅）。再點一次可復原。預期方向：A、C、S、R 存在有利；I 缺席有利。

從第一項開始吧。

三個中間項是 A·S·R、A·C·S·~I、A·~I。合起來：

A·S·R + A·C·S·~I + A·~I → Y
⇒ A·S·R + A·~I → Y

因為 A·C·S·~I 是 A·~I 的子集（凡是 A·C·S·~I 的案例也都是 A·~I 的案例），所以它在邏輯上是多餘的，可以拿掉。結論：施壓成功有兩條路徑——① 有科學建議支持、未來還要打交道、且國內有反響（A·S·R）；② 有科學建議支持、且改變行為不麻煩（A·~I）。

複雜解中間解（最佳）簡約解
A·~C·~S·~I·~R
A·C·S·~I·~R		⊆A·~I⊆~I
A·S·I·R⊆A·S·R⊆S·R
📌 這個中間解為什麼是「最佳」？

它是複雜解的超集、簡約解的子集，而且只納入容易反事實，把簡約解中那些困難的反事實（例如「沒有科學建議也能成功」）排除在外。它在複雜與簡約之間取得平衡，所用的程序正好模仿了傳統案例導向的比較研究。另外，Stokke 原本就把 A 放進結果，是依照 Ragin（2000）的建議：先做必要條件檢驗，再做充分性分析。

4. 互動實驗室：方向性預期如何改變中間解 · Interactive lab

軟體推導中間解時，你要告訴它每個條件的方向性預期（directional expectation）：存在有利、缺席有利，或沒有明確預期（皆可）。下面的比較器會即時用布林最小化重算三種解，並在卡諾圖上標出哪些餘項被當作容易反事實（中間解納入）、哪些只被簡約解使用（困難或缺乏依據的反事實）。

試試看這幾個實驗：

  • 表 9-1 把 C 改成「缺席」：中間解會停在 A·B·~C——因為 ~C 現在符合預期，刪掉它反而是困難反事實。
  • 表 9-1 把 B 改成「缺席」、C 改成「缺席」：中間解變成 A·~C，這就是原書提到的第二個中間解。
  • 表 9-2 把 A 改成「皆可」：A 仍然保留（沒有預期 ≠ 可以刪除）；但若把 A 改成「缺席」，中間解就一路退到簡約解 ~I + S·R。
  • 把所有條件都設成「皆可」：中間解 = 複雜解，因為沒有任何反事實有理論依據。
想一想：表 9-2 若把 I 也設成「存在有利」，為什麼中間解仍然是 A·S·R + A·~I？

照逐項規則，A·S·I·R 中的 I 這時符合預期，不該刪。但軟體（fsQCA 與 R 的 QCA 套件）的實作是：先把每一項導出的容易反事實集中起來，再連同正面列一起做一次布林最小化。由 A·~C·~S·~I·~R 與 A·C·S·~I·~R 導出的容易反事實（例如 A·C·S·~I·R、A·~C·S·~I·R），正好能讓 A·S·I·R 和 A·S·~I·R 合併成 A·S·R。所以最後的式子可能比你「一項一項手算」的結果再簡潔一點，但它用到的仍然只是容易反事實。

5. 反事實分析與案例導向研究 · Counterfactual analysis and case-oriented research

從傳統量化研究的角度看，案例導向的比較研究似乎「行不通」（Achen, 2005）：

  • 統計分析在大樣本時效果最好——顯著性較容易達到，也較能滿足技術上嚴苛的假設；小樣本、中等樣本則常違反這些假設。
  • 案例研究者熟悉案例，傾向提出組合式的因果論斷；這對稀少的跨案例證據提出更高的要求，也與主流量化技術「估計各變數淨效應、獨立效應」的核心邏輯相衝突。

但案例導向研究有自己的邏輯與嚴謹性：它是組態的，所以必須檢驗條件組合。大多數量化研究反而缺乏這種嚴謹——因為「配對比較」會吃掉自由度與統計檢定力。

表面上的質疑

研究條件組合就得面對有限多樣性，只好用假想案例做思想實驗。這看起來違反了「實證」社會科學的規範。

本章的回應

許多反事實其實是例行的，因為它們是容易的。QCA 把這些容易反事實形式化並明白寫出，納入跨案例分析中，任何人都能檢查。

🔑 案例研究者一直都在用容易反事實

回到情境一：一位傳統案例研究者面對 A·B·C·~D → Y 的案例，會圍繞「被認為重要的因素」A、B、C 來寫因果敘事；若知識告訴他這些條件是「存在」才有幫助，他很快就得出 A·B·C → Y，而不會特別說明「我假設了 A·B·C·D 也會成功」。這種反事實常在建構解釋的過程中「即時」、隱含地完成。QCA 做的事情一模一樣，只是把它攤在陽光下。

本章也凸顯社會科學一個極重要的特性：它建立在理論與實質知識之上，而不只是方法技術。正是這些知識，讓我們能評估反事實是否合理；中間解的程序，等於提供了一個以知識為基礎來處理有限多樣性的方法，把既有知識直接編進實證結果的結構中。

6. 實用附錄：推導中間解 · Practical appendix

複雜解與簡約解的推導是「自動」的：前者把所有餘項設為「假」，後者把所有餘項都列為可用的反事實（不論容易或困難）。中間解則不是自動的，因為它需要你輸入理論與實質知識——也就是每個條件的方向性預期。清晰集與模糊集都一樣，只要使用真值表演算法即可同時得到三種解。

ℹ️ 原書的例子：怎麼設定預期？（結果 =「避免貧窮」）
  • 「至少有高中學歷」→ 選 Present（存在）：低教育與低收入的關聯眾所周知。
  • 「父母是低收入戶」→ 選 Absent（缺席）：它的缺席才有助於避免貧窮。
  • 「居住在城市」→ 選 Present or Absent（皆可）：美國城鄉都有大量貧窮人口，沒有明確預期；甚至城市與鄉村居民脫貧可能走不同的組態。

為什麼要編碼正確？假設「高中學歷·已婚·無子女」→ 避免貧窮，但沒有「無高中學歷·已婚·無子女」的案例。若你沒有把高中學歷設為「存在有利」，軟體就可能用這個餘項把解簡化成「已婚·無子女」——等於宣稱教育無關緊要。這是一個困難反事實；而經驗上，資料中已婚無子女的正面案例其實都至少有高中學歷。正確編碼就能擋下這種沒有根據的簡化。

開啟真值表演算法

點選 Analyze → Truth Table Algorithm，指定結果（Y）與前因條件。

完成真值表編碼

依第 7 章附錄的方式：刪除未達頻數門檻的列，依一致性在結果欄填入 1 或 0。沒有案例的列會被當作餘項。

按下 Standard Analyses

在真值表視窗底部點 Standard Analyses。程式會先推導複雜解，接著推導簡約解。

（如果出現）選擇質蘊含項 Prime Implicants

若有多個質蘊含項（prime implicants）都能涵蓋同一些正面列，fsQCA 會跳出 Prime Implicant Chart 要你勾選。請依理論與案例知識選擇最有意義的項；本章的兩個例子不會出現此視窗，因為解是唯一的。

設定方向性預期（Intermediate Solution 對話框）

對每個條件選擇 Present（存在有利）、Absent（缺席有利）或 Present or Absent（無預期）。Stokke 的例子：A、C、S、R 選 Present；I 選 Absent。

閱讀輸出

輸出視窗依序列出 COMPLEX SOLUTION、PARSIMONIOUS SOLUTION、INTERMEDIATE SOLUTION，每個解都附有一致性與覆蓋度，中間解還會列出你設定的假設（Assumptions）。報告時，一般以中間解為主，並說明方向性預期的理由。

R 的 QCA 套件用 minimize() 的兩個參數控制三種解：include = "?" 允許使用餘項；dir.exp 設定方向性預期。以下程式碼已在 QCA 3.25 實際執行過，結果與原書相同。

library(QCA)
# 原書表 9-2：每列一種組態（真實分析時每列是一個案例）
stokke <- data.frame(
  A = c(1,1,1,0,1,1,1,1),  # 科學建議
  C = c(0,0,0,0,1,1,1,0),  # 違反承諾
  S = c(1,0,0,0,1,1,1,0),  # 未來影響
  I = c(1,1,1,1,1,1,0,0),  # 不便
  R = c(1,0,1,0,1,0,0,0),  # 國內反響
  Y = c(1,0,0,0,1,0,1,1)   # 施壓成功
)
tt <- truthTable(stokke, outcome = "Y",
                 conditions = "A, C, S, I, R", incl.cut = 1)

# ① 複雜（保守）解：預設不使用餘項
minimize(tt, details = TRUE)
#   M1: A*S*I*R + A*~C*~S*~I*~R + A*C*S*~I*~R -> Y

# ② 簡約解：允許使用所有餘項
minimize(tt, include = "?")
#   M1: ~I + S*R -> Y

# ③ 中間解：允許餘項＋方向性預期（新版寫法：條件名稱，~ 表示缺席有利）
ints <- minimize(tt, include = "?",
                 dir.exp = c("A", "C", "S", "~I", "R"))
ints
#   M1: A*~I + A*S*R -> Y

# 列出中間解用到的容易反事實（6 列餘項）
ints$i.sol$C1P1$EC
⚠️ dir.exp 的版本差異
  • 新寫法（QCA 3.x 後期版本，本頁以 3.25 驗證）：用條件名稱，"~I" 表示「缺席有利」；沒有預期的條件直接不寫。也可寫成一個字串 dir.exp = "A, C, S, ~I, R"。
  • 舊寫法（早期版本與許多舊教材）：依 conditions 的順序給數字向量，1 = 存在、0 = 缺席、"-" = 無預期，例如 dir.exp = c(1, 1, 1, 0, 1)。3.25 版仍接受此寫法、結果相同，但順序一錯就會默默算錯，建議改用新寫法。
  • 表 9-1 的對應寫法：dir.exp = c("A", "B", "C", "D") → 中間解 A*B；若 C 不寫（無預期）→ 中間解停在 A*B*~C。

想看更完整的 R 操作與模糊集範例，可參考本站主教材〈QCA with R〉中關於最小化與中間解的章節。

一般而言，中間解是首選，因為它通常最容易詮釋：有限多樣性嚴重時，複雜解幾乎沒有簡化、難以解讀；簡約解則因納入大量（容易與困難的）反事實，可能簡約得不切實際。中間解依據研究者的理論與實質知識，在兩者之間取得平衡。

7. 本章重點、名詞與自我測驗 · Review

  1. 容易反事實：把一個理論上有益的條件加入已知會產生結果的組態；困難反事實：從已知會產生結果的組態中移除一個理論上有貢獻的條件。兩者是連續體，判斷依據是學術社群的既有知識。
  2. QCA 的複雜解（不用餘項）與簡約解（用任何能簡化的餘項）是複雜／簡約連續體的兩端，兩者都建立在相同證據上，只差在對反事實的容忍度。
  3. 解之間保持子集關係：複雜解 ⊆ 中間解 ⊆ 簡約解。中間解必須保留簡約解中的所有條件（子集原則）。
  4. 最佳中間解的程序：從複雜解的每一項中，刪除與既有知識（方向性預期）不一致的條件，但不刪簡約項中的條件。Stokke 的例子得到 A·S·R + A·~I。
  5. 簡約解可能丟掉案例研究者一眼就會看到的共同條件（例如 Stokke 的 A），中間解則把它保留下來。
  6. 案例研究者在建構解釋時，一直都隱含、即時地使用容易反事實；QCA 的貢獻是把它們明確化、透明化。
  7. 軟體操作：fsQCA 的 Standard Analyses ＋ Present／Absent／Present or Absent；R 的 minimize(tt, include = "?", dir.exp = ...)。

自我測驗

觀察到 A·B·~C → Y，且理論認為 C 的存在有利於 Y。反事實「A·B·C → Y」屬於哪一種？

所有反事實都涉及沒有案例的組態，這不是判斷依據。關鍵是方向：把預期有利的 C 加進一個本來就成功的組合，結果理應仍會出現——容易。

下列哪一個關係永遠成立？

納入的反事實越多，涵蓋的列就越多，集合越大。複雜解不納入任何反事實，所以最小；簡約解納入最多，所以最大。

表 9-1 中，複雜解為 A·B·~C、簡約解為 A。若理論認為所有條件都是「存在」有利，最佳中間解是？

刪除 ~C（與「C 存在有利」不一致）只需容易反事實；刪除 B 則是困難反事實；B·~C 違反子集原則（會涵蓋負面列 0100）；A·B·~C·D 甚至比複雜解還窄。

在 Stokke 的例子中，為什麼 A·S·I·R 裡的 S 和 R 不能刪除？

中間項必須是對應簡約項的子集；簡約項 S·R 包含 S 和 R，中間項就必須保留它們。真正可刪的是 I（違反「I 缺席有利」）。

Stokke 例子的簡約解 ~I + S·R 被批評的主要原因是？

簡約解是邏輯上正確的，但它靠困難反事實（例如「沒有科學建議也會成功」）把 A 刪掉了。中間解 A·S·R + A·~I 則保留了 A。

在 fsQCA 設定中間解時，「居住在城市」對「避免貧窮」沒有明確預期，應該選？

沒有理論依據時選 Present or Absent。此時軟體不會把該條件的任何刪除視為容易反事實，條件會被保留（除非簡約解本身就不含它）。

在 R 的 QCA 套件（新版）中，下列哪一個寫法對應「A、C、S、R 存在有利，I 缺席有利」？

中間解需要 include = "?"（允許使用餘項）加上方向性預期；I 缺席有利要寫成 "~I"。舊版數字寫法則是 c(1,1,1,0,1)。

Ragin 說案例導向研究者是反事實的「老手」，意思是？

例如面對 A·B·C·~D 的成功案例，他們會直接圍繞 A、B、C 建構論證，等於默默假設「有 D 也會成功」。QCA 只是把這個步驟明確化。
