CHAPTER 1

社會科學研究中的集合關係：基本概念

Set Relations in Social Research: Fundamental Principles
對應原書第 1 章（中譯本頁 3–14）

「小農戶是風險規避的」「民主國家彼此不打仗」——社會科學的理論大多用文字表達，而這些文字背後其實是集合的語言。本章要帶你看見：這類主張應該用集合關係來檢驗，而不是被硬改寫成「兩個變數有沒有相關」。

🎯 讀完本章，你應該能夠……
  1. 把一句文字理論改寫成「A 是 B 的子集合」的形式。
  2. 說明為什麼集合關係是非對稱的，而相關係數是對稱的。
  3. 分辨兩種案例導向的研究策略，並對應到必要條件與充分條件。
  4. 在 2×2 交叉表中，指出檢驗必要性、充分性時各自該看哪兩格。
  5. 讀懂一張清晰集真值表，並理解「只差一個條件」就能簡化的邏輯。

1. 集合關係的本質 · The nature of set relations

最基本的集合關係是子集合（subset）：如果 A 裡的每一個成員也都是 B 的成員，我們就說 A 是 B 的子集合，記作 A ⊆ B。

有些子集合關係是「定義上」就成立的：狗一定是哺乳動物、新教徒一定是基督徒。這類關係不需要研究，查字典就知道。社會科學真正關心的是另一種：子集合關係背後反映了某種因果或構成上的連結，因此需要被解釋。

定義性的子集合

  • 狗 ⊆ 哺乳動物
  • 新教徒 ⊆ 基督徒 ⊆ 有神論者

成立的理由是「定義如此」，不需要理論解釋。

需要解釋的子集合（本書焦點）

  • 宗教基本教義派 ⊆ 政治保守派
  • 已開發國家 ⊆ 擁有強大公民社會的國家
  • 第三波民主化中採議會制的國家 ⊆ 民主化失敗的國家

它是巧合，還是背後有因果機制？這需要理論與案例知識來詮釋。

🔑 核心觀念：文字理論 = 集合陳述

當理論說「小農戶是風險規避者」，它的意思其實是：「小農戶」這個集合，被包含在「風險規避者」這個集合裡面。Ragin 主張：既然理論是用集合的語言講的，就應該用集合的方式去檢驗它，而不是先把它翻譯成「農地大小與風險態度有負相關」再丟進迴歸模型。

互動 練習：把文字理論翻譯成集合關係

選一句理論陳述，再選出它對應的集合關係。

請先選擇答案。

2. 集合關係是非對稱的 · Set relations are asymmetric

集合關係與相關關係最大的差別在於對稱性。

  • 「已開發國家是民主國家」（已開發 ⊆ 民主）這句話，並沒有說未開發國家就不民主。即使世界上有很多貧窮但民主的國家，這句話依然成立。
  • 但如果你把它改寫成相關假設——「開發程度與民主程度正相關」——那些「貧窮但民主」的國家就會拉低相關係數，看起來像是反證。
⚠️ 社會科學最常見的錯誤之一

把非對稱的集合論主張，默默改寫成對稱的相關假設。改寫後的版本其實多說了一句原本沒說的話（「未開發國家就不民主」），然後再用這句多出來的話去否定原本的理論。

📌 Ragin 歸納的五個特徵

社會科學中的集合關係：① 連結的是因果或整體性的關係（不只是定義）；② 依賴理論與知識來詮釋；③ 是社會科學理論化的核心（因為理論多是文字陳述）；④ 是非對稱的，不該被改寫成相關論證；⑤ 即使相關很弱，集合關係也可能非常強。

想一想：「民主和平論」說的是哪一種關係？

「民主國家彼此不打仗」的意思是：「雙方都是民主國家」的國家配對 ⊆ 「沒有發生戰爭」的國家配對。重點不在民主配對與非民主配對的戰爭比率「差多少」，而在於民主配對的戰爭比率是不是趨近於零。當然，和平還有很多其他途徑，所以「民主」與「和平」的相關係數可能不高——但這不影響民主和平論本身。

3. 兩種重要的集合關係：必要與充分 · Two kinds of set relations

做質性或案例導向研究的學者，雖然很少用集合論的術語，卻天天在找「共同點（commonalities）」。Ragin 稱他們是「隱性的布林主義者（implicit Booleans）」。找共同點有兩種策略：

策略一：從結果出發策略二：從條件出發
研究者的問題「有這個結果的案例，有什麼共同的前因？」「有這組前因的案例，是否都出現同樣的結果？」
集合關係結果 ⊆ 條件條件（或條件組合）⊆ 結果
對應概念必要條件（necessary）充分條件（sufficient），尤其是條件組合的充分性
例子Skocpol：每場社會革命之前都有國家崩潰 → 國家崩潰可能是革命的必要條件經濟低度發展＋黨派分化＋行政權弱的國家是否全都民主崩潰？
ℹ️ 兩個重要的補充

① 不必完美：如果「幾乎所有」民主存續的國家都採總統制，研究者通常也會把它當作兩者有整體關聯的證據。第 3 章會教你如何用「一致性」來量化「幾乎」。

② 不一定要講因果：建立「明確連結（explicit connection）」本身就是社會科學的核心工作。例如觀察到「民主崩潰的國家都是前殖民地」，不一定要立刻宣稱殖民經驗是原因。

4. 相關方法為什麼會錯過關係 · Correlational methods sometimes miss connections

把條件與結果的有／無交叉，就得到最常見的 2×2 表。Ragin 把四個格子編號如下：

從「明確連結」的角度看，相關係數有兩個缺點：

  1. 它只處理相對差異：例如總統制存活率 60% vs. 議會制 35%，兩者確實有相關，但這不是集合關係——兩組都有大量例外。
  2. 它把兩種不同的因果評估混在一起：必要性與充分性被揉成一個數字。更奇怪的是，在相關分析裡很重要的格 3（條件與結果都不存在），對兩種集合關係的評估都沒有直接幫助。
🔑 為什麼這件事很重要？

相關係數不只是一個雙變數統計量——多元迴歸、因素分析、結構方程模型，全都建立在「相關矩陣＋平均數＋標準差」之上。所以這些複雜的量化技術，從根本上就繞過了「明確連結」的研究。這也是許多質性研究者對相關方法敬而遠之的根源。研究明確連結，等於是把變數導向研究最基本的單位——相關——拆解開來。

5. QCA 與真值表 · QCA and the truth table

QCA（質性比較分析）以集合論為基礎，特別擅長處理因果複雜性（causal complexity）：同一個結果，可能來自好幾種不同的條件組合——Ragin 稱之為不同的「前因配方（recipes）」。

QCA 的核心工具是真值表（truth table）：列出前因條件在邏輯上所有可能的組合，以及每一種組合對應的經驗結果。它直接落實了前面的「策略二」（充分性）：把條件組合相同的案例放在一起，看它們的結果是否一致。

互動 條件越多，組合爆炸得越快
k4個前因條件

下表是 Ragin 舉的假想例子：學者根據理論，認為民主存續的關鍵涉及四個條件——總統制、強而有力的行政、低度政黨分化、非共產主義的過去。四個條件 → 24 = 16 種組合。

點選任一列結果為「是」的列，系統會找出和它只差一個條件、且結果也為「是」的列，並示範如何合併。

「—」表示該組合沒有任何經驗案例（這在第 8、9 章會成為「有限多樣性」與「反事實」的核心議題）。

簡化的邏輯是這樣的：如果某案例具備全部四個條件且民主存續，另一個案例具備其中三個（第四個不具備）也民主存續，那麼兩者不同的那個條件，對結果來說就不重要；真正的關鍵是兩者共有的那三個條件。這種「逐步合併」就是布林最小化的直覺基礎。

真值表是會「長大」的

從假設的配方到真值表，常常會反過來刺激研究者修改配方。假設最後一列（四條件齊備）的案例結果不一致：有的存續、有的崩潰。研究者應該回頭比較這兩群案例。若發現崩潰的案例都有嚴重的菁英分裂，就可以把「沒有菁英分裂」加進配方，用 5 個條件（32 列）重建真值表。

📌 真值表的真正價值

它把研究過程形式化：提供一個把案例當作「有異同的組態」來比較的框架，並讓你看清楚哪裡一致、哪裡矛盾。這需要深厚的案例知識，以及理論、案例與真值表之間的反覆來回。

展望

到目前為止談的都是清晰集（crisp set）：一個案例要嘛在集合內（1），要嘛不在（0）。這看起來很粗糙，也是很多人誤以為集合論只適用於名義變數的原因。下一章將引入模糊集（fuzzy set），讓隸屬分數可以落在 0 到 1 之間。

6. 實作：建構清晰集真值表 · Practical appendix

假設你有一個由 0／1 變數組成的資料集（1 = 存在，0 = 缺席）。建構真值表有兩個目的：① 看案例如何分布在各種條件組合上；② 看每種組合中的案例，在結果上有多一致。

建立資料集

在 fsQCA 直接輸入，或匯入 Excel 的 CSV（逗號分隔）、SPSS 的 Tab 分隔檔。第一列放變數名稱，名稱不可有空格或標點；缺失值留空白。

開啟真值表演算法

點選 Analyze → Truth Table Algorithm（舊版需先選 Crisp Sets，新版已不需要），在對話框指定結果與前因條件。也可以分析結果的「否定」。

看「number」欄：設定頻數門檻

真值表依頻數排序並顯示累積百分比。案例少時，門檻設為「至少 1 個案例」，把 0 案例的列刪除；案例很多時可提高門檻，以避免測量誤差造成的雜訊。刪除方式：點選要刪除的第一列 → Edit → Delete current row to last row。

看「consistency」欄：編碼結果

清晰集的一致性 = 該列中呈現結果的案例比例。接近 1.0 表示高度一致；0.30–0.70 表示這列案例結果分歧（矛盾列）。依此在結果欄手動輸入 1 或 0。

用矛盾列引導下一步研究

找出矛盾列裡的案例深入比較，常能發現一個可加入真值表的新條件來解決矛盾，然後重新設定真值表。

本網站主教材使用 R 的 QCA 套件（Duşa），以下是同樣的流程：

# 假想資料：每列一個國家，0/1 編碼
library(QCA)
dem <- data.frame(
  P    = c(1,1,1,0,0,1,0,1),   # 總統制
  S    = c(1,1,1,1,0,0,1,1),   # 強行政
  L    = c(1,0,0,1,1,0,0,1),   # 低政黨分化
  N    = c(1,1,0,1,0,0,1,1),   # 非共產過去
  SURV = c(1,1,1,1,0,0,0,0)    # 民主存續
)

# 建立真值表：n.cut = 頻數門檻、incl.cut = 一致性門檻
tt <- truthTable(dem, outcome = "SURV",
                 conditions = c("P", "S", "L", "N"),
                 n.cut = 1, incl.cut = 0.8,
                 show.cases = TRUE, sort.by = "n")
tt   # incl = 該列一致性；OUT = 1 表示通過門檻、0 表示未通過

注意第 1 個與第 8 個國家條件完全相同（四條件齊備），結果卻一個存續、一個崩潰——這一列的一致性只有 0.5，低於門檻，OUT 會是 0。這正是「回頭研究案例」的訊號。想看完整的 R 操作，可參考本站主教材〈Ch.3 清晰集 csQCA〉。

7. 本章重點、名詞與自我測驗 · Review

  1. 社會科學理論多以文字表達，而文字陳述本質上是集合陳述（例如「A 是 B」＝ A ⊆ B）。
  2. 集合關係是非對稱的；把它改寫成對稱的相關假設，會不當擴張原理論，是常見錯誤。
  3. 相關弱，集合關係仍可能很強（表 1-2：φ 只有 0.44，但議會制 ⊆ 失敗完美成立）。
  4. 結果 ⊆ 條件 → 評估必要性（看格 1、格 2）；條件 ⊆ 結果 → 評估充分性（看格 2、格 4）。格 3 對兩者都不直接相關。
  5. 真值表列出 2k 種條件組合，把「相同組合的案例結果是否一致」系統化，是處理因果複雜性的關鍵工具。

自我測驗

「宗教基本教義派是政治保守的」這句話，最適合的集合表述是？

「A 是 B」表示 A 的成員都屬於 B，所以基本教義派是保守派的子集合。很多保守派不是基本教義派，並不影響這個主張。

研究者發現「許多貧窮國家也是民主國家」。這對「已開發國家是民主國家」的主張有什麼影響？

集合關係是非對稱的：主張只談已開發國家，沒說未開發國家就不民主。但這些案例會落在 2×2 表的「格 1」型位置，拉低相關係數。

想檢驗「X 是 Y 的必要條件」，在 2×2 表中主要該看哪兩格？

必要性 = 結果 ⊆ 條件。所以要看「結果存在」的案例（格 1、格 2），希望格 1（有結果卻沒條件）越少越好。

在相關分析中很重要，但對必要性與充分性評估都沒有直接幫助的是哪一格？

格 3 的案例「什麼都沒有」。它會提高相關係數，卻無法告訴你條件是否必要或充分。

有 5 個前因條件的清晰集真值表，共有幾列？

每個條件有「存在／缺席」兩種狀態，組合數 = 2k = 25 = 32。

真值表中某一列的案例結果互相矛盾（有的有結果、有的沒有）。Ragin 建議的第一步是？

矛盾列是研究的線索。比較該列內正向與負向案例，常能找出被遺漏的條件（例如「沒有菁英分裂」），加入後重建真值表。
